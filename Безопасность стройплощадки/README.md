# Безопасность строительной площадки

Проект для подготовки ответов на вопросы по дисциплине "Безопасность строительной площадки".

## Структура папок

```
SiteSafety/
├── Презентации/           — Файлы презентаций (источник для анализа)
├── Пособия и методички/   — Пособия, методички, СП (нормативная база)
├── Вопросы/               — Список вопросов к экзамену/зачёту
└── Ответы/                — Составленные ответы на вопросы
```

## Рабочий процесс

1. Загрузить презентации в папку `Презентации/`
2. Загрузить пособия, методички и СП в папку `Пособия и методички/`
3. Загрузить список вопросов в папку `Вопросы/`
4. Анализ материалов и составление ответов → `Ответы/`
