## Вопрос 41. Основные сведения о процессе горения

### Треугольник горения (рисунок)

```
              🔥
             ╱  ╲
            ╱ПЛАМЯ╲
           ╱        ╲
          ╱──────────╲
         ╱ИСТОЧНИК    ╲
        ╱ ЗАЖИГАНИЯ    ╲
       ╱────────────────╲
      ╱   ГОРЮЧЕЕ        ╲
     ╱   ВЕЩЕСТВО         ╲
    ╱──────────+───────────╲
   ╱    ОКИСЛИТЕЛЬ (O₂)     ╲
  ╱──────────────────────────╲
  ════════════════════════════

  Убрать любой элемент = тушение!
```

### Формула теплоты горения

    Q = m · q_н  [кДж]

где: m — масса горючего (кг); q_н — низшая теплота сгорания (кДж/кг).

| Вещество | q_н, кДж/кг | Т_самовоспл., °C |
|---|---|---|
| Древесина | 13 800 | 255–280 |
| Бензин | 43 600 | 255–370 |
| Ацетон | 30 600 | 500 |
| Полиэтилен | 47 100 | 306 |

### Концентрационные пределы (КПРП)

    НКПР ≤ C_гор ≤ ВКПР  → возможен взрыв/пожар

где: НКПР — нижний концентрационный предел; ВКПР — верхний.

## Вопрос 42. Оценка пожарной опасности строительных материалов

### Классификация (рисунок)

```
    Строительные материалы
    ├── НГ (негорючие) ──── камень, кирпич, бетон, металл
    └── Г (горючие)
        ├── Г1 (слабо) ───── ГВЛ, гипсокартон с добавками
        ├── Г2 (умеренно) ── ПВХ линолеум, дерево огнезащ.
        ├── Г3 (нормально) ─ ДСП, фанера, необработ. дерево
        └── Г4 (сильно) ──── пенополистирол, необраб. ткань
```

### Пожарно-технические характеристики

| Показатель | Группы |
|---|---|
| Горючесть | НГ, Г1, Г2, Г3, Г4 |
| Воспламеняемость | В1, В2, В3 |
| Распространение пламени | РП1, РП2, РП3, РП4 |
| Дымообразование | Д1, Д2, Д3 |
| Токсичность | Т1, Т2, Т3, Т4 |

### Формула критической поверхностной плотности теплового потока (КППТП)

    q_кр = Q_кр / (S · t)  [кВт/м²]

где Q_кр — критическая мощность; S — площадь; t — время.

## Вопрос 43. Обеспечение пожарной безопасности бытовых зданий

### Схема бытового городка (рисунок)

```
    ┌──── Территория стройплощадки ────────────────┐
    │                                               │
    │  ┌────────────┐   ≥ 24 м   ┌───────────────┐ │
    │  │ Строящийся │←──────────→│               │ │
    │  │  объект    │            │  Бытовки      │ │
    │  │            │            │  (≤ 10 шт.)  │ │
    │  └────────────┘            │  ≥ 1 м между  │ │
    │                            │  бытовками    │ │
    │                            └───────────────┘ │
    │                    ≥ 15 м ↕                   │
    │                            ┌───────────────┐ │
    │  ┌──────────────┐          │  Бытовки      │ │
    │  │ Склад ГСМ   │←─≥18м──→│  (группа 2)   │ │
    │  └──────────────┘          └───────────────┘ │
    │                                               │
    │ ⊕ Огнетушитель  ① Пожарный гидрант          │
    └───────────────────────────────────────────────┘
```

### Требования
- Расстояние от бытовок до объекта ≥ 24 м (IV–V ст. огнестойк.).
- Между группами бытовок ≥ 15 м.
- До складов ГСМ ≥ 18 м.
- Группа ≤ 10 бытовок, внутри — ≥ 1 м.
- Огнетушитель в каждом помещении.
- Проживание людей **запрещено**.

## Вопрос 45. Способы тушения пожара на стройплощадке

### Принципы тушения (рисунок)

```
    ┌──────────────────────────────────────────┐
    │          ПРИНЦИПЫ ТУШЕНИЯ                │
    ├────────────┬──────────────┬──────────────┤
    │ ОХЛАЖДЕНИЕ │  ИЗОЛЯЦИЯ   │  РАЗБАВЛЕНИЕ │
    │  (вода)    │ (пена, порош)│ (CO₂, инерт) │
    │ T < T_восп │ Преграда O₂  │ O₂ < 14%    │
    └────────────┴──────────────┴──────────────┘
```

### Классы пожаров и средства тушения

| Класс | Горящее вещество | Средство тушения |
|---|---|---|
| A | Твёрдые (дерево, бумага) | Вода, пена, порошок |
| B | Жидкости (бензин, масло) | Пена, порошок, CO₂ |
| C | Газы (метан, пропан) | Порошок, CO₂ |
| D | Металлы (Al, Mg) | Спецпорошки |
| E | Электроустановки | CO₂, порошок (НЕ вода!) |

### Формула теплоотвода водой

    Q_отв = m_в · [c · (100 − T_в) + r]  [кДж]

где: m_в — масса воды (кг); c = 4,19 кДж/(кг·°C) — теплоёмкость; T_в — начальная температура воды; r = 2260 кДж/кг — теплота парообразования.

## Вопрос 46. Сеть пожарного водоснабжения на стройплощадке

### Схема пожарного водоснабжения (рисунок)

```
    Городской водопровод
    ═══════╦═══════════════════════╦═══════
           ║                       ║
    ┌──────╨───────┐       ┌──────╨───────┐
    │  Ввод на     │       │   Пожарный   │
    │ стройплощадку│       │   резервуар  │
    └──────╥───────┘       │  V = Q·t·3,6 │
           ║                └──────────────┘
    ═══════╬═══════════════════════║
    ① ──── ╬ ──── ① ──── ① ──── ① 
    Гидранты   (через ≤ 150 м)
    
    ① — пожарный гидрант
         5 м ≤ d(①,здание) ≤ 50 м
```

### Формула запаса воды в резервуаре

    V = Q · t · 3,6  [м³]

где: Q — расход воды (л/с); t — время тушения (≥ 3 часа); 3,6 — переводной коэффициент.

### Нормативные расходы воды на пожаротушение

| Объём здания, тыс. м³ | Расход, л/с |
|---|---|
| до 3 | 10 |
| 3–5 | 15 |
| 5–20 | 20 |
| 20–50 | 30 |
| свыше 50 | 40 |

### Требования
- Гидранты через ≤ 150 м.
- Расстояние гидрант–здание: 5–50 м.
- Продолжительность тушения ≥ 3 часов.
- Подъезды к гидрантам — свободны.
