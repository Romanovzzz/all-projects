## Вопрос 31. Назначение и конструкция страховочного каната

### Конструкция (рисунок)

```
    ← 12 м макс. →
    ⊗══════════════════════════════⊗
    │ Анкерная      Канат ∅8–12мм  │ Анкерная
    │ точка         стальной       │ точка
    │               ↕ Провис       │
    │               ≤ L/20         │
    │                              │
    ╔═══════════════╗              │
    ║   Колонна     ║              │
    ╚═══════════════╝              │
    
    Крепление карабина:  ──◊── (привязь работника)
                           ↕
                        Канат
```

### Формула расчёта провиса каната

    f = q·L² / (8·T)

где: q — погонный вес каната + вес работника (приведённый); L — длина пролёта; T — сила натяжения (≥ 22 кН).

### Требования
- Нагрузка ≥ 22 кН (2200 кгс).
- К одному пролёту — не более 2 работников.
- Испытание — не реже 1 раза в 6 мес.
- При L > 12 м — промежуточные опоры.

## Вопрос 33. Выносные грузоприёмные площадки

### Конструкция (рисунок)

```
    ┌────────────────────┐ 
    │    Перекрытие       │
    │                    │
    ╠════════════════════╬═══════════════╗
    ║   Крепление к      ║  Консольные  ║ Ограждение
    ║   перекрытию       ║  балки       ║ h ≥ 1,1 м
    ╠════════════════════╬═══════════════╣
    ║                    ║   НАСТИЛ      ║
    ║                    ║   Площадка    ║ ← Откидной
    ║                    ║              ║    борт
    ╠════════════════════╬═══════════════╝
    │    Перекрытие       │
    │                    │
    └────────────────────┘

    Длина консоли: обычно 2,0–3,0 м
    Ширина площадки: 2,0–2,5 м
```

### Формула расчёта консольной балки

    M_max = q · L² / 2  (момент в заделке)

    σ = M_max / W ≤ R_y  (проверка прочности)

где q — нагрузка; L — вылет консоли; W — момент сопротивления; R_y — расчётное сопротивление стали.

### Требования
- Коэффициент запаса прочности ≥ 2.
- Настил — сплошной, зазоры ≤ 5 мм.
- Табличка с допустимой нагрузкой.
- Сигнальное освещение в тёмное время.

## Вопрос 34. Страховочная и удерживающая привязь

### Конструкция привязей (рисунок)

```
  а) Страховочная привязь:     б) Удерживающая привязь:

        ┌──┐ ← Спинная            ┌──┐
        │  │    точка              │  │
      ╔═╧══╧═╗ крепления        ╔═╧══╧═╗
      ║ Плечо ║                  ║      ║
      ╠═══════╣ ← Грудная       ╠═══════╣
      ║       ║    точка         ║      ║
      ╠═══════╣                  ║  ╔═══╩═══╗← Поясной
      ║ ╔═══╗ ║                  ║  ║ Пояс  ║   ремень
      ╠═╝   ╚═╣ ← Набедрен.     ╚══╩═══════╝
      ║       ║    лямки              │
      ╚═══════╝                       │← Строп
                                      │   (огранич.
                                      ⊗   длины)
```

### Сравнение
| Параметр | Страховочная | Удерживающая |
|---|---|---|
| Назначение | Останов падения | Предотвращение попадания |
| Конструкция | Полная обвязка | Пояс + строп |
| Допустимое падение | До 6 м (с амортизатором) | Падение исключено |
| Нагрузка на тело | ≤ 6 кН (с амортизатором) | — |

### Формула длины стропа с амортизатором

    L_строп ≤ H_св − 1,5 − ΔL_аморт

где H_св — свободное пространство под работником; 1,5 м — рост работника; ΔL_аморт — удлинение амортизатора при срабатывании (обычно 1,75 м).

### Требования (Приказ 782н)
- Обязательна при высоте ≥ 1,8 м без ограждений.
- Осмотр перед каждым использованием.
- Испытание — 1 раз в 12 месяцев.
- Срок службы — 3–5 лет.

## Вопрос 35. Опасные и вредные факторы при бетонных работах

### Классификация факторов (рисунок)

```
    ┌─────────────────────────────────────────┐
    │     БЕТОННЫЕ РАБОТЫ — ФАКТОРЫ          │
    ├─────────────────────┬───────────────────┤
    │   ОПАСНЫЕ           │   ВРЕДНЫЕ         │
    ├─────────────────────┼───────────────────┤
    │ Обрушение опалубки  │ Контакт с цементом│
    │ Падение с высоты    │ Шум (> 80 дБА)    │
    │ Поражение эл.током  │ Вибрация          │
    │ Разрыв шлангов      │ Пыль цемента      │
    │ Падение бадьи       │ Повыш. влажность  │
    └─────────────────────┴───────────────────┘
```

### Формула давления бетонной смеси на опалубку

    P = γ_б · H_б · K_1 · K_2

где: γ_б — плотность бетонной смеси (2400 кг/м³); H_б — высота слоя бетона; K_1 — коэффициент, зависящий от скорости бетонирования; K_2 — коэффициент, зависящий от температуры.

При скорости бетонирования V (м/ч):

    P = γ_б · (0,27·V + 0,78) · K_1 · K_2  (при H > 2 м)

## Вопрос 36. Безопасность при монтаже вертикальной опалубки

### Схема вертикальной опалубки (рисунок)

```
    ╔═══════════════════════╗
    ║                       ║
    ║     Бетонируемая      ║
    ║     конструкция       ║
    ║     (стена/колонна)   ║
    ║                       ║
    ╠═══════╦═══════════╦═══╣
    ║ Щит 1 ║ Стяжной   ║Щит 2
    ║       ║ болт →────║
    ║       ╠═══════════╣   ║
    ║       ║           ║   ║
    ╚═══════╩═══════════╩═══╝
      ↕           ↕
    Подкос      Подкос
    (инвент.)  (инвент.)
```

### Формула расчёта стяжного болта

    N = P · a · b  (усилие в стяжном болте)

    σ = N / A_нт ≤ R_bt  (проверка прочности)

где P — боковое давление бетона; a, b — шаг болтов по высоте и длине; A_нт — площадь сечения нетто болта.

## Вопрос 37. Безопасность при монтаже горизонтальной опалубки

### Схема горизонтальной опалубки (рисунок)

```
    Разрез:
       ┌──── Укладка бетона ────┐
    ═══╬════════════════════════╬═══ ← Палуба
       ║                        ║
       ║   ← Балка (ригель) →  ║
       ║                        ║
    ═╦═╩════════════════════════╩═╦═ ← Балки
     ║                            ║
     ║   Телескопическая стойка   ║
     ║   (домкрат)                ║
     ║                            ║
     ╩════════════════════════════╩  ← Подкладки
    ═══════════ Основание ═════════
```

### Формула допустимого прогиба

    f_max ≤ L/400  (для палубы опалубки)
    f_max ≤ L/500  (для несущих элементов)

### Требования
- Стойки раскрепляются горизонтальными связями в 2-х ярусах.
- Бетон укладывается равномерно, без концентрации.
- Приёмка опалубки — комиссионно, с составлением акта.

## Вопрос 38. Безопасность арматурных работ

### Схема арматурного каркаса (рисунок)

```
    Арматурный каркас колонны:

    ┌────── Хомуты (поперечная арматура) ──────┐
    │  ┌──┐ шаг 150–300 мм  ┌──┐               │
    │  │∅12│──────────────────│∅12│← Рабочая     │
    │  └──┘                  └──┘   арматура    │
    │  ┌──┐                  ┌──┐   (продольн.) │
    │  │∅12│──────────────────│∅12│               │
    │  └──┘                  └──┘               │
    └─── Хомут ∅6–8 ─────── Хомут ──────────────┘
    
    Защитный слой a₀:
    a₀ ≥ ∅_арм (но ≥ 20 мм для колонн, ≥ 25 мм для фундам.)
```

### Формула определения массы каркаса (для строповки)

    G = Σ(n_i · ρ_ст · π·d_i²/4 · L_i)

где n_i — количество стержней; d_i — диаметр; L_i — длина; ρ_ст = 7850 кг/м³.

### Требования
- Концы стержней загнуты или закрыты колпачками.
- Ходьба по арматуре — только по трапам ≥ 0,6 м.
- Сварка — в защитной маске и перчатках.

## Вопрос 39. Меры безопасности при подаче и укладке бетонной смеси

### Способы подачи (рисунок)

```
  а) Краном в бадье:        б) Бетононасосом:

    ╱╲                         ╔══════╗
   ╱  ╲ ← Стрела              ║Насос ║
  ╱    ╲                       ╠══════╣
  ┃     ├── ← Строп            ║      ╟── Трубопровод ──→
  ┃     │                      ║      ║     ∅100–150 мм
  ┃   ┌─┴─┐                    ╚══════╝
  ┃   │   │ ← Бадья            Давление: 3–10 МПа
  ┃   │90%│   (заполнение                          
  ┃   │   │    ≤ 90%)           Дальность: до 300 м 
  ┃   └─┬─┘                    (горизонт.)
  ┃     │ ← Затвор
```

### Формула скорости бетонирования

    V = Q / (b · h_сл)  [м/ч]

где Q — производительность подачи (м³/ч); b — ширина конструкции; h_сл — толщина слоя (0,3–0,5 м).

### Требования
- Бадья ≤ 90% объёма.
- Продувка трубопровода — без людей в зоне выхода.
- Вибратор — через УЗО.

## Вопрос 40. Демонтаж опалубки, меры безопасности

### Порядок демонтажа (рисунок)

```
    Этапы распалубки:

    1. Проверка прочности бетона
       (неразрушающий контроль)
       R_бет ≥ 0,7·R_проект (несущая)
       R_бет ≥ 0,2 МПа (боковая)
    
    2. Последовательность:
       
       Монтаж:  Щиты→Стойки→Ригели→Палуба
       Демонтаж: Палуба→Ригели→Стойки→Щиты
                 (обратная последовательность!)
    
    3. Схема:
       ┌─── Сначала боковые ───┐
       │    ╔══════════════╗     │
       │    ║  Конструкция  ║   │ → 1-й этап
       │    ╚══╦═══════╦══╝     │
       │       ║       ║        │
       └── Затем несущие ──────┘ → 2-й этап
              (стойки)
```

### Формула набора прочности бетона по времени

    R_t = R_28 · lg(t) / lg(28)  (при t ≥ 3 сут., нормальные условия)

где R_t — прочность в возрасте t суток; R_28 — проектная (28-суточная) прочность.

### Критерии распалубки
| Тип конструкции | Требуемая прочность |
|---|---|
| Боковые (стены, колонны) | ≥ 0,2–0,3 МПа |
| Плиты пролётом ≤ 6 м | ≥ 70% R_проект |
| Плиты пролётом > 6 м | ≥ 80% R_проект |
| Балки пролётом > 8 м | 100% R_проект |
