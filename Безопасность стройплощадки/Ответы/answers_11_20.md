# Ответы на вопросы по дисциплине «Безопасность на строительной площадке» (Часть 2: Вопросы 11–20)

---

## Вопрос 11. Потенциальные опасные зоны стройплощадки

### Определение
**Потенциальные (возможные) опасные зоны** — зоны, в которых опасные производственные факторы действуют не постоянно, а возникают периодически, при выполнении определённых работ или при определённых условиях.

### Схема потенциальных опасных зон (рисунок)

```
    Вид сверху (стройгенплан):

               R_max (макс. вылет стрелы)
            ┌───────────── · ─────────────┐
            │             ╱╲              │
            │            ╱  ╲  ← Стрела   │
            │    ┌──────╱ □ ╲──────┐      │
            │    │      Кран       │      │
    Зона    │    │   ┌─────────┐  │      │ Зона
    отлёта  │    │   │ Объект  │  │      │ перемеще-
    груза → │    │   │строящ.  │  │      │ ← ния
    (Lотл)  │    │   │         │  │      │   машин
            │    │   └─────────┘  │      │
            │    │   Монтажная    │      │
            │    │   зона (Lотл) │      │
            │    └────────────────┘      │
            └────────────────────────────┘
```

### Формула определения границы монтажной зоны

    Lмз = Lн + Lотл

где: Lн — наружный контур здания; Lотл — дальность отлёта падающего предмета при высоте H:

    Lотл = 0,32 · √H  (для свободно падающего предмета с H ≤ 20 м)

| Высота здания H, м | Дальность отлёта Lотл, м |
|---|---|
| 10 | 3,5 |
| 20 | 5,0 |
| 30 | 7,0 |
| 70 | 10,0 |
| 120 | 15,0 |

### Формула определения границы зоны работы крана

    Rоз = Rmax + 0,5·Lгр + Lотл

где: Rmax — макс. вылет стрелы; Lгр — длина наибольшего поднимаемого груза; Lотл — отлёт груза при обрыве.

## Вопрос 12. Причины травматизма при земляных работах

### Основные причины
1. **Обрушение грунта** — разработка грунта с недостаточно устойчивыми откосами.
2. **Превышение нормативной глубины** вертикальной выемки без крепления.
3. **Недостаточная прочность крепления** вертикальных стенок выемки.
4. **Действие динамических нагрузок** (транспорт, механизмы) вблизи бровки.
5. **Подмыв откосов** грунтовыми или ливневыми водами.
6. **Нахождение работников в зоне действия ковша** экскаватора.

### Схема обрушения откоса (рисунок)

```
    До обрушения:          После обрушения:

    ├── берма ──┤          ├── берма ──┤
    ▓▓▓▓▓▓▓▓▓▓▓│          ▓▓▓▓▓▓▓▓╲╲╲│
    ▓▓▓▓▓▓▓▓▓▓▓│H_крит    ▓▓▓▓▓▓▓▓ ╲╲│
    ▓▓▓▓▓▓▓▓▓▓▓│          ▓▓▓▓▓▓▓▓  ╲│
    ▓▓▓▓▓▓▓▓▓▓▓│  ↓       ▓▓▓▓▓▓▓▓░░░│← Обруш.
    ────────────┘          ▓▓▓▓▓▓▓▓░░░│   грунт
               Выемка     ────────░░░░┘
                                  Выемка
```

## Вопрос 13. Условия для обеспечения устойчивости земляной выемки

### Критическая высота вертикального откоса

    H_крит = (2c / γ) · tg(45° + φ/2)

где: c — удельное сцепление грунта (кПа); γ — плотность грунта (кН/м³); φ — угол внутреннего трения (°).

### Пример расчёта
Дано: глина, γ = 20 кН/м³, c = 40 кПа, φ = 15°.

    H_крит = (2·40/20) · tg(45° + 15°/2) = 4,0 · tg(52,5°) = 4,0 · 1,303 = 5,21 м

### Допустимая глубина вертикальной выемки без крепления
| Вид грунта | Допустимая глубина, м |
|---|---|
| Песчаный | 1,0 |
| Супесь | 1,25 |
| Суглинок | 1,50 |
| Глина | 2,00 |

### Факторы устойчивости
- Вид грунта, его φ и c.
- Глубина выемки.
- Грунтовые воды (снижают сцепление).
- Нагрузки на берме (техника, материалы).
- Динамические воздействия (вибрация).

## Вопрос 14. Выбор элементов уступа для связного грунта

### Профиль равноустойчивого откоса (рисунок)

```
    ─────────── Берма ──→ q (нагрузка)
    ╲                     ↓↓↓↓↓↓↓
     ╲ Кривая
      ╲ равноустойч.     ├──────────────
       ╲ откоса          │
        ╲                │   z₁
         ╲               │───→ x₁
          ╲              │   z₂
           ╲             │───→ x₂
            ╲            │   z₃
             ╲           │───→ x₃
              ╲          │
               ╲         │   H
                ╲────────┘
                  Дно выемки
```

### Формула координат равноустойчивого откоса

Горизонтальная координата xi на глубине zi:

    x_i = (c / (γ · zi)) · K(φ)

где K(φ) — коэффициент, зависящий от угла внутреннего трения:

    K(φ) = [cos²φ · ln(γ·zi / (γ·zi − 2c·sinφ))] / sin²φ

### Учёт нагрузки на берму ρ₀ (кПа)
При наличии дополнительной нагрузки от техники на берме глубина zi заменяется на:

    z'i = zi + ρ₀/γ

## Вопрос 15. Безопасная разработка земляной выемки с откосом

### Нормативные значения крутизны откосов (H:L)
| Вид грунта | H = 1,5 м | H = 3 м | H = 5 м |
|---|---|---|---|
| Насыпной | 1:0,67 | 1:1 | 1:1,25 |
| Песчаный | 1:0,5 | 1:1 | 1:1 |
| Супесь | 1:0,25 | 1:0,67 | 1:0,85 |
| Суглинок | 1:0 | 1:0,5 | 1:0,75 |
| Глина | 1:0 | 1:0,25 | 1:0,5 |

### Схема откоса (рисунок)

```
    ├──── берма ────┤
    │               │╲
    │   Нагрузка    │ ╲
    │   от техники  │  ╲  α = arctg(1/m)
    │               │   ╲
    │───────────────│    ╲   H
    │ Безопасное    │     ╲
    │ расстояние    │      ╲
    ├───────────────┤───────╲─────
                    │← L = m·H →│
                    └────────────┘
                      Дно выемки

    где m — заложение откоса (горизонтальное)
    Крутизна = 1:m (H:L)
```

### Меры безопасности
- При глубине > 5 м крутизна устанавливается **расчётом** и указывается в ППР.
- Ограждение бровки — высотой 1,2 м.
- Переходные мостики через траншеи — ширина ≥ 0,6 м c перилами 1,1 м.

## Вопрос 16. Безопасная разработка вертикальной земляной выемки

### Условия допустимости вертикальных стенок без крепления
- **Песчаный грунт** — до 1,0 м
- **Супесь** — до 1,25 м
- **Суглинок** — до 1,50 м
- **Глина** — до 2,00 м

### Схема вертикальной выемки с креплением (рисунок)

```
    ┌──────────────────────────┐ ← Берма
    │     ▓▓▓▓▓▓▓▓▓▓▓▓▓       │
    │     ▓      Грунт  ▓     │
    │     ▓              ▓    │
    ═══╦══▓ ← Забирка    ▓══╦═══
       ║  ├──────────────┤  ║
       ║  │← Распорка →│  ║ ← Стойка
       ║  ├──────────────┤  ║
       ║  │← Распорка →│  ║
    ═══╩══├──────────────┤══╩═══
          └──── Дно ─────┘
           H (глубина выемки)
```

### Требования
- За состоянием стенок ведётся систематическое наблюдение.
- Для спуска — лестницы ≥ 0,6 м, через каждые 25–30 м.
- При длине > 25 м устанавливаются не менее 2 лестниц.

## Вопрос 17. Конструкции крепления вертикального откоса

### Типы крепления (рисунок)

```
  а) Горизонтально-рамное    б) Вертикально-рамное

  ═══╦════════════╦═══        ║  ║  ║  ║  ║  ║
     ║ ← Забирка ║           ║  ║  ║  ║  ║  ║
  ───╬────────────╬───     ═══╬══╬══╬══╬══╬══╬═══
     ║   Распорка ║        ← Прогон →
  ───╬────────────╬───     ═══╬══╬══╬══╬══╬══╬═══
     ║ ← Забирка ║           ║  ║  ║  ║  ║  ║
  ═══╩════════════╩═══        ║  ║  ║  ║  ║  ║
     ↑             ↑
   Стойка       Стойка

  в) Анкерное крепление (для глубоких выемок):

  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓
  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓
  ▓▓▓▓______▓▓▓▓▓ ← Анкер (тяга)
  ├──╱      ║
  │╱        ║ ← Шпунтовая стенка
  │         ║     или щит
  └─────────╝
```

### Расчёт распорки (нагрузка от грунта)

Давление грунта на стенку (по Кулону):

    σ_a = γ·z·K_a − 2c·√K_a

    K_a = tg²(45° − φ/2)

Равнодействующая активного давления:

    E_a = 0,5·γ·H²·K_a − 2c·H·√K_a

где H — глубина выемки.

### Требования
- Крепление выступает над бровкой на 15 см.
- Разборка — снизу вверх по мере засыпки.

## Вопрос 18. Конструкции шпунтового крепления

### Профиль Ларсена (рисунок)

```
    Вид сбоку (один элемент):

      ┌───────────────────┐
      │                   │ ← Полка (стенка)
      │                   │
    ╔═╝                   ╚═╗
    ║    Замок        Замок  ║
    ╚═══════════════════════╝

    Соединение шпунтин:

    ╔═╗╔═╗╔═╗╔═╗╔═╗
    ║ ║║ ║║ ║║ ║║ ║  ← Сплошная стенка
    ╚═╝╚═╝╚═╝╚═╝╚═╝    (замки обеспечивают
                         герметичность)
```

### Конструктивная схема шпунтового ограждения

```
    ─────── Берма ──────

    ╔═══╗ ← Обвязочный пояс
    ║   ╠─────────────╣   ║ ← Распорка
    ║   ║             ║   ║
    ║   ╠─────────────╣   ║ ← Распорка (2-й ярус)
    ║   ║             ║   ║
    ║   ║  Котлован   ║   ║  H
    ║   ║             ║   ║
    ╚═══╝             ╚═══╝
    Шпунт              Шпунт
    Ларсена            Ларсена
```

### Формула расчёта глубины забивки шпунта

    t ≥ H · √(K_a / K_p)

где: t — глубина забивки ниже дна; H — глубина выемки; Ka — коэффициент активного давления; Kp — коэффициент пассивного давления:

    K_p = tg²(45° + φ/2)

## Вопрос 19. Причины травматизма при погрузо-разгрузочных работах

### Основные причины
1. **Неправильная строповка** — несоответствующие стропы, неверные схемы.
2. **Нахождение людей в зоне крана** — под стрелой, в зоне перемещения груза.
3. **Перегрузка крана** — масса груза > грузоподъёмности при данном вылете.
4. **Обрыв канатов и строп** — износ, перегрузка.
5. **Потеря устойчивости крана** — неподготовленное основание.
6. **Неисправность тормозных устройств**.

### Формула грузоподъёмности крана

    Q = Q_max · (R_max / R)  (при r ≤ R ≤ R_max)

где Q_max — макс. грузоподъёмность; R_max — макс. вылет стрелы; R — текущий вылет.

### Грузовой момент (условие устойчивости крана)

    M_гр = Q · R ≤ M_уст = G_пр · a

где G_пр — вес противовеса; a — плечо противовеса; M_уст — удерживающий момент.

### Коэффициент запаса устойчивости

    K_уст = M_уст / M_гр ≥ 1,4

## Вопрос 20. Требования безопасности при погрузке-разгрузке: транспорт и краны

### Требования к транспорту
- Площадка — спланирована, твёрдое покрытие, уклон ≤ 5°.
- Расстояние между транспортом: в ряд ≥ 1 м, рядом ≥ 1,5 м.
- Механизированная разгрузка обязательна для грузов > 50 кг.

### Требования к кранам
- Уклон основания ≤ 2° (для башенных на рельсах).
- Пробный подъём на 200–300 мм для проверки строповки.
- Груз перемещается на высоте ≥ 0,5 м выше препятствий.

### Схема безопасного расположения крана и транспорта (рисунок)

```
    ┌─────────────────────────────┐
    │    Зона обслуживания крана  │
    │         ╔═══╗               │
    │    ←R→  ║Кр.║               │
    │         ╚═══╝               │
    │      ↕ 0,5 м min            │
    │    ┌───────┐                │
    │    │ Груз  │                │
    │    └───────┘                │
    │    ← 1,5 м →┌────────┐     │
    │              │ Авто 1 │←1 м│
    │              └────────┘    │
    │              ┌────────┐    │
    │              │ Авто 2 │    │
    │              └────────┘    │
    └─────────────────────────────┘
```

### Требования к стропальщикам
- Возраст ≥ 18 лет, обучение и аттестация.
- Обязательная проверка массы груза и исправности стропов.
