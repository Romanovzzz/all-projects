## Вопрос 21. Требования к складированию железобетонных конструкций

### Правила складирования
| Элемент | Положение | Высота штабеля |
|---|---|---|
| Фундаментные блоки | Горизонтально | ≤ 4 рядов (≤ 2,6 м) |
| Стеновые панели | Вертикально в кассетах | — |
| Плиты перекрытий | Горизонтально | ≤ 2,5 м |
| Колонны | Горизонтально | ≤ 2 м |
| Фермы, балки | Вертикально в кассетах | — |
| Перемычки | Горизонтально | ≤ 5 рядов |

### Схема складирования плит (рисунок)

```
    ┌────────────────────────────┐
    │     Плита перекрытия       │  Ряд 4 (макс.)
    ├── ■ Прокладка 40×100 ─────┤
    │     Плита перекрытия       │  Ряд 3
    ├── ■ Прокладка ────────────┤
    │     Плита перекрытия       │  Ряд 2
    ├── ■ Прокладка ────────────┤
    │     Плита перекрытия       │  Ряд 1
    ├── ■ Подкладка 100×150 ────┤
    └────────── Грунт ──────────┘
    
    Важно: прокладки строго
    по вертикали одна над другой!
    Монтажные петли ↑ вверх.
    Проходы между штабелями ≥ 1 м.
```

### Схема складирования панелей в кассетах

```
    ┌─┐┌─┐┌─┐┌─┐  ← Стеновые панели
    │ ││ ││ ││ │     (в вертикальном
    │ ││ ││ ││ │      положении)
    │ ││ ││ ││ │
    ╚═╝╚═╝╚═╝╚═╝  ← Кассета
    ════════════════   (стальная рама)
```

## Вопрос 22. Причины травматизма при монтаже конструкций

### Основные причины
1. **Падение монтируемых конструкций** — неправильная строповка, обрыв стропов.
2. **Падение людей с высоты** — незащищённые перекрытия, без ограждений.
3. **Придавливание работников конструкцией** — при наведении, установке.
4. **Потеря устойчивости** до установки постоянных связей.
5. **Обрушение ранее смонтированных конструкций**.
6. **Падение инструмента** с высоты.

### Формула определения границы опасной зоны при монтаже

    R_оп = R_max + 0,5·L_гр + L_отл

| H (высота), м | L_отл (отлёт), м |
|---|---|
| до 10 | 4 |
| до 20 | 7 |
| до 70 | 10 |
| до 120 | 15 |
| до 200 | 20 |
| до 300 | 25 |

## Вопрос 23. Недостатки выполнения монтажных работ на стройплощадке

### Типичные нарушения (рисунок)

```
    Правильно:             Неправильно:

    ┌───┐ Связи ┌───┐     ┌───┐         ┌───┐
    │ Ф1├═══════┤ Ф2│     │ Ф1│         │ Ф2│
    └─┬─┘       └─┬─┘     └─┬─┘ Нет    └─┬─┘
      │ Расчалки  │          │ связей!    │
      ╲          ╱           │            │
       ╲   ╱╲  ╱             │    ╱╲      │
        ╲╱    ╲╱              │  ╱    ╲    │
    Якорь      Якорь          │╱        ╲  │
                            ⚠ Потеря устойчивости!
```

### Последствия нарушений
- Обрушение конструкций (групповые НС).
- Падение работников с высоты.
- Падение элементов на нижестоящих.

## Вопрос 24. Монтажные устройства для временной устойчивости конструкций

### Виды монтажных устройств (рисунок)

```
  а) Одиночный кондуктор:    б) Расчалки:

       ┌───┐                     ┌───┐
       │Кол│                     │Кол│
       │он.│                     │он.│
    ╔══╪═══╪══╗               ╱  │   │  ╲
    ║  │   │  ║  Зажимы     ╱    │   │    ╲
    ║  │   │  ║           ╱      │   │      ╲
    ╚══╪═══╪══╝         ╱ 30°    │   │  30° ╲
       │   │          ⊗──────────┴───┴──────⊗
    [Фундамент]         Якорь          Якорь

  в) Групповой кондуктор (РШИ):

    ┌───┐─────────┌───┐
    │Кол│ Ригели  │Кол│
    │ 1 │ (рамы)  │ 2 │
    └───┘─────────└───┘
      │    ╱╲╱╲    │
      │   ╱    ╲   │  ← Шарнирные
    ┌───┐─────────┌───┐   связи
    │Кол│         │Кол│

    └───┘─────────└───┘
```

### Требования
- Временные крепления снимаются только после установки проектных связей.
- Расчалки натягиваются талрепами.
- Количество и тип определяются в ППР.

## Вопрос 25. Обеспечение временной устойчивости колонн

### Порядок монтажа (рисунок)

```
    1. Подъём и наведение:     2. Закрепление:

         ╱╲                        ┌───┐
        ╱  ╲ ← Строп               │Кол│
       ╱    ╲                       │он.│
      ╱      ╲                   ╔══╪═══╪══╗
     ╱        ╲                  ║  │   │  ║← Кондуктор
    ┌──────────┐                 ╚══╪═══╪══╝
    │ Колонна  │                    │   │
    │          │                 ╔══╪═══╪══╗
    └──────────┘                 ║ Стакан ║← Клинья
                                 ╚═══════╝
                                [Фундамент]

    3. Выверка:                 4. Замоноличивание:
       Теодолит →                  Бетон ≥ 70% R
       проверка вертик.            → снятие кондуктора
```

### Требования к клиновому крепление в стакане

    δ = (b_ст − b_кол) / 2  (зазор между колонной и стаканом)

где b_ст — внутренний размер стакана; b_кол — размер колонны. Клинья вставляются в зазор с 4-х сторон.

## Вопрос 26. Обеспечение временной устойчивости фермы

### Схема временного крепления фермы (рисунок)

```
    Вид сверху:

    ════════════════════ ← Ферма 1
    ╲    ╱ ╲    ╱       ← Расчалки (4 шт.)
     ╲  ╱   ╲  ╱
      ╲╱     ╲╱
      ⊗       ⊗         ← Якоря
    
    Вид сбоку (раскрепление 2-х ферм):

    ┌──╱╲╱╲╱╲╱╲╱╲──┐  ← Ферма 1
    │  │         │  │
    ├──╱╲╱╲╱╲╱╲╱╲──┤  ← Ферма 2
    │              │
    ═══════════════════ ← Распорки /
       Связи по ВП       монтажные связи
```

### Правила монтажа
- Первая ферма: ≥ 4 расчалок (в 1/4 пролёта, в обе стороны).
- Вторая ферма соединяется с первой постоянными или временными связями.
- Расстроповка — **только после** установки связей!
- До установки связей — запрещено нагружать верхний пояс (прогоны, панели).

## Вопрос 27. Характеристики рабочего места на высоте, причины падения

### Определение работы на высоте (Приказ 782н)
- Падение с высоты ≥ **1,8 м**.
- Подъём/спуск > 5 м по лестнице с углом > 75°.
- Работы < 2 м от неогражденного перепада > 1,8 м.
- Высота ограждения < 1,1 м.

### Анализ основных причин падения (статистика)

```
    Причины падения с высоты (%):

    Отсутствие ограждений  ████████████████ 35%
    Неисп. СИЗ            ████████████     25%
    Обрушение подмостей    ██████████       20%
    Скользкие поверхности  ██████          12%
    Сильный ветер          ████             8%
```

### Ограничения по погодным условиям
- Ветер ≥ 15 м/с — работы на высоте **запрещены**.
- Гололёд, гроза, туман (видимость < 50 м) — работы прекращаются.

## Вопрос 28. Защитное ограждение рабочего места на высоте

### Конструкция ограждения (рисунок)

```
            ← Поручень
    ╔═══════════════════════╗  h ≥ 1,1 м
    ║                       ║
    ╠───────────────────────╣  ← Промежуточный
    ║       ≤ 450 мм       ║     элемент
    ╠───────────────────────╣
    ║                       ║
    ╠═══════════════════════╣
    ║▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓║  ← Бортовая доска
    ╚═══════════════════════╝     h ≥ 100 мм
    ═══════════════════════════ ← Рабочая площадка

    Нагрузка на ограждение ≥ 70 кгс (горизонт.)
```

### Параметры
| Параметр | Значение |
|---|---|
| Высота ограждения | ≥ 1,1 м |
| Горизонтальная нагрузка | ≥ 70 кгс (700 Н) |
| Шаг промежуточных элементов | ≤ 450 мм |
| Высота бортовой доски | ≥ 100 мм |

## Вопрос 30. Конструктивные решения монтажных подмостей

### Типы подмостей (рисунок)

```
  а) Блочные (пакетные):      б) Вышка-тура:

    ┌──────────────┐              ┌────┐
    │   Настил     │  Перила      │Наст│ Перила
    ╠══════════════╣  1,1 м       ╠════╣ 1,1 м
    ║  ╱  ╲   ╱  ╲║              ║    ║
    ║╱      ╲╱    ╲║              ║    ║  до 12 м
    ║        ╲    ╱║              ║    ║
    ║   ╱  ╲  ╱  ╱ ║              ║    ║
    ╚════════════╝              ╚════╝
    ═══ Перекрытие ═══          ⊙    ⊙ ← Колёса
                                ▬ Тормоз ▬
```

### Формула расчёта устойчивости вышки-туры

    K_уст = M_уст / M_опр ≥ 1,5

    M_уст = G · a/2  (удерживающий момент от веса)
    M_опр = F_в · H  (опрокидывающий от ветра)

где G — вес вышки; a — ширина базы; F_в — ветровая нагрузка; H — высота.

### Требования
- Настилы — сплошные, зазоры ≤ 5 мм.
- Ограждение — перила 1,1 м + бортовая доска 100 мм.
- Колёса фиксируются тормозами перед работой.
