# Ответы на вопросы по дисциплине «Безопасность на строительной площадке» (Часть 1: Вопросы 1–10)

---

## Вопрос 1. Инженерные решения по охране труда при разработке ПОС

### Общие положения и актуальность
Безопасность проведения строительных работ основывается на качественной разработке вопросов охраны труда на этапе проектирования. В первую очередь это касается разработки **проекта организации строительства (ПОС)**. Аналогичные задачи решаются при подготовке **проекта производства работ (ППР)**, а также при разработке стройгенплана, календарного плана и технологических карт на отдельные строительные операции.

### > **Примечание:** Нумерация вопросов сохранена в соответствии с оригинальным списком (вопросы 2 и 4 отсутствуют).\n\nСостав инженерных решений по охране труда в ПОС\n- Календарный план строительства, определяющий последовательность и сроки возведения объектов.\n- Определение этапов строительства и потребности в ресурсах (кадры, техника).
- Разработка стройгенплана с указанием постоянных и потенциальных опасных зон, ограждений, проездов, проходов.
- Определение **монтажных зон** — зон возможного падения предметов, границы которых определяются наружными контурами строящегося объекта плюс величина ожидаемого отлёта падающего предмета.
- Определение **зон работы грузоподъёмных механизмов** — башенных кранов, подъёмников и др.
- Разработка схем движения транспорта по площадке (кольцевые, сквозные, тупиковые).
- Размещение административно-бытовых зданий (бытовок) за пределами опасных зон.
- Проектирование временного электроснабжения, водоснабжения и освещения площадки.
- Разработка мероприятий по пожарной безопасности (расстановка средств пожаротушения, размещение пожарных гидрантов).

### Схема стройгенплана (рисунок)

```
    ┌─────────────────────────────────────┐
    │           СТРОИТЕЛЬНАЯ              │
    │            ПЛОЩАДКА                 │
    │   ┌───────────┐                     │
    │   │  Строящ.  │← Монтажная зона    │
    │   │  объект   │   (Lотл)           │
    │   └───────────┘                     │
    │       ↕ Рабочая зона крана          │
    │   ╔═══════╗                         │
    │   ║ Кран  ║→ Rmax (макс. вылет)     │
    │   ╚═══════╝                         │
    │                                     │
    │   [Бытовки]  [Склады]  [Мойка]     │
    │                                     │
    │ ═══════> Дорога (кольцевая) ═══════>│
    │                                     │
    ├── Ограждение h≥2,0 м ──────────────┤
    └─────────────────────────────────────┘
```

### Нормативная база
- Приказ Минтруда РФ от 16.11.2020 № 782н — Правила по охране труда при работе на высоте.
- Приказ Минтруда РФ от 29.10.2021 № 776н — Примерное положение о системе управления охраной труда.
- СП 48.13330.2019 «Организация строительства».

## Вопрос 3. Конструкции ограждения строительной площадки

### Назначение ограждений
Ограждение строительной площадки обеспечивает:
- Предотвращение доступа посторонних лиц на территорию строительства.
- Обозначение границ строительной площадки.
- Защиту пешеходов и транспорта от воздействия опасных факторов.

### Типы ограждений
1. **Защитно-охранное ограждение** — без козырька, для площадок, не примыкающих к пешеходным зонам. Высота панели — не менее 2,0 м.
2. **Защитно-охранное ограждение с козырьком** — применяется в условиях городской застройки, если рядом проходят пешеходные зоны.
3. **Сигнальное ограждение** — для обозначения границ потенциально опасных зон внутри площадки.

### Конструктивная схема ограждения с козырьком (рисунок)

```
         Козырёк (угол 20°)
        ╱▓▓▓▓▓▓▓▓▓▓╲
       ╱  Подкос     │
      ╱               │   ← Панель ограждения
     ╱                │      h ≥ 2,0 м
    ╱                 │
   ├──────────────────┤
   │ Бортовая доска   │ ← h ≥ 100 мм
   ├──────────────────┤
   │  Поручень 1,1 м  │
   │  Перила          │
   │  ╔═══════════╗   │
   │  ║ Тротуар   ║   │ ← Панель тротуара
   │  ║ ≥ 1,5 м   ║   │      (деревянный настил)
   │  ╚═══════════╝   │
   └──────────────────┘
         Грунт
```

### Размерные требования
- Высота панели ограждения — не менее **2,0 м**.
- Козырёк — выступ не менее **0,6 м**, угол наклона ~20° к горизонту.
- Тротуар — ширина не менее **1,5 м**, ограждён перилами h ≥ 1,1 м.
- Бортовая доска — высотой не менее **100 мм**.

## Вопрос 5. Устройство внутриплощадочных дорог

### Назначение
Внутриплощадочные дороги обеспечивают транспортную доступность всех участков строительной площадки для подвоза материалов, конструкций, оборудования и передвижения строительной техники.

### Схемы внутриплощадочных дорог (рисунок)

```
  а) Кольцевая           б) Сквозная          в) Тупиковая

  ┌──────┐              Выезд 1               ┌──────┐
  │      │                ↓                    │      │
  │ Объект│  ═══>     ════════════     ═══>   │ Объект│  ═══>
  │      │  ↑↓             ↑↓                  │      │
  │      │  <═══     ════════════     ═══>   │      │
  └──────┘                ↑                    └──────┘╗
                      Выезд 2                         ╔╝
                                              Разворот ⟳
                                              (R ≥ 12 м)
```

### Параметры дорог
- **Двухполосное движение**: ширина дорожного полотна — **6 м**.
- **Однополосное движение**: ширина — **3,5 м** (при ограниченных размерах территории).
- Радиус закругления — не менее **12 м** для одиночных автомобилей, не менее **12–18 м** для автопоездов.
- На однополосных дорогах устраиваются **разъездные площадки** шириной 6 м через каждые 100 м.

### Типы дорожного покрытия
- Естественный грунт (для лёгких нагрузок, сухих грунтов)
- Щебёночное или гравийное покрытие
- Дороги из сборных **железобетонных плит** (основной вариант для стройплощадок)

## Вопрос 6. Внутриплощадочные дороги с твёрдым покрытием

### Дороги из сборных железобетонных плит

### Типы железобетонных дорожных плит
| Марка плиты | Габариты, м | Масса, т | Нагрузка на колесо, т |
|---|---|---|---|
| ПД 1-6 | 1,5 × 1,75 × 0,18 | 1,2 | 6 |
| ПД 1-9,5 | 1,5 × 1,75 × 0,18 | 1,2 | 9,5 |
| ПД 2-9,5 | 1,5 × 3,0 × 0,18 | 2,0 | 16 |
| ПД 3-23 | 1,5 × 3,0 × 0,22 | 2,0 | 23 |

### Конструктивная схема дороги из ж/б плит (рисунок)

```
    Разрез дорожной одежды:

    ┌──────────── Плита ПД ────────────┐
    │  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓  │ t = 180–220 мм
    ├──────────────────────────────────┤
    │  ○○○ Песчаная постель ○○○○○○○○  │ t = 100–250 мм
    ├──────────────────────────────────┤
    │:::::: Уплотнённый грунт ::::::::│
    └──────────────────────────────────┘
             i = 1–3% (уклон)
```

### Технология устройства
- Дорожные плиты стропятся за монтажные петли и с помощью крана укладываются на **песчаную постель** толщиной 10–25 см.
- Основание устраивается с лёгким уклоном (1–3%) для удаления дождевой воды.
- Дороги рассчитываются под нагрузку на ось от 6 т и выше.

## Вопрос 7. Требования к производственному освещению

### Виды освещения на стройплощадке

| Вид | Назначение | Минимальная освещённость |
|---|---|---|
| Рабочее | Обеспечение нормальных условий работ | По нормам (2–100 лк) |
| Аварийное | Продолжение работ или эвакуация | ≥ 2 лк |
| Охранное | Охрана территории | ≥ 0,5 лк |
| Сигнальное | Обозначение опасных зон | — |

### Формула расчёта числа прожекторов

    n = E · S / (F · η · μ)

где: E — требуемая освещённость (лк); S — площадь освещаемой территории (м²); F — световой поток одного прожектора (лм); η — КПД светильника; μ — коэффициент использования (0,12–0,35).

### Требования безопасности
- Освещение не должно создавать слепящего эффекта.
- Равномерность освещения — Emin/Emax ≥ 1:5.
- Питание светильников — 220 В; для переносных — не более 12 В.

## Вопрос 8. Рабочее освещение, нормативы освещённости

### Нормативы освещённости
| Вид работ / территория | Минимальная освещённость, лк |
|---|---|
| Общее освещение стройплощадки | 2 |
| Проезды и проходы | 5 |
| Земляные работы (механизированные) | 10 |
| Монтаж строительных конструкций | 20–30 |
| Бетонные и каменные работы | 20 |
| Отделочные работы | 50–100 |
| Сварочные работы | 30–50 |

### Расчёт высоты мачты прожекторного освещения

    H = √(F · η / (π · E))

где H — высота мачты (м); F — световой поток (лм); η — КПД; E — требуемая освещённость (лк).

### Источники рабочего освещения
- Прожекторы заливающего света на мачтах h = 15–45 м.
- Светильники на опорах ЛЭП.
- Переносные и передвижные осветительные установки.

## Вопрос 9. Устройство прожекторного освещения

### Конструктивная схема (рисунок)

```
        ╔══╗  ← Прожекторы (3–20 шт.)
        ║  ║     угол наклона 15–45°
    ┌───╢  ╟───┐
    │   ║  ║   │  ← Площадка обслуживания
    │   ║  ║   │
    │   ║  ║   │  Мачта стальная h = 15–45 м
    │   ║  ║   │
    │   ║  ║   │
    │   ║  ║   │
    ╚═══╩══╩═══╝  ← Фундамент + заземление
```

### Формулы расчёта

Расстояние между мачтами:

    L = 2H · tg(α/2)

где H — высота мачты; α — угол охвата прожектора.

Допустимый наклон прожектора к горизонту:

    θ ≤ arctan(H / D)

где D — расстояние от мачты до ближайшего рабочего места (для исключения ослепления).

### Требования безопасности
- Прожекторные мачты заземляются (R_заз ≤ 4 Ом).
- Направление светового потока не должно ослеплять машинистов кранов и водителей.
- На одной мачте — от 3 до 20 прожекторов.

## Вопрос 10. Постоянные опасные зоны стройплощадки

### Определение
**Постоянные опасные зоны** — зоны, в которых действуют постоянные (непрерывные) опасные производственные факторы.

### Виды постоянных опасных зон

```
    Классификация постоянных опасных зон:

    ┌─────────────────────────────────────┐
    │   ПОСТОЯННЫЕ ОПАСНЫЕ ЗОНЫ          │
    ├─────────────────────────────────────┤
    │ 1) Вблизи неизолированных          │
    │    токоведущих частей (ЛЭП)        │
    │    → Lбез ≥ 0,6–10 м              │
    │      (в зависимости от напряжения) │
    ├─────────────────────────────────────┤
    │ 2) У неогражденных перепадов       │
    │    по высоте ≥ 1,8 м              │
    ├─────────────────────────────────────┤
    │ 3) Зоны повышенного шума          │
    │    > ПДУ = 80 дБА                 │
    ├─────────────────────────────────────┤
    │ 4) Зоны повышенной температуры    │
    │    > ПДТ (при сварочных работах)   │
    ├─────────────────────────────────────┤
    │ 5) Зоны повышенной                │
    │    загазованности/запылённости     │
    │    > ПДК                          │
    └─────────────────────────────────────┘
```

### Безопасные расстояния от ЛЭП

| Напряжение, кВ | Безопасное расстояние, м |
|---|---|
| до 1 | 0,6 |
| 1–20 | 1,0 |
| 35–110 | 4,0 |
| 150 | 5,0 |
| 220 | 6,0 |
| 330–500 | 10,0 |

### Меры защиты
- Ограждение постоянных опасных зон сигнальными и защитными ограждениями.
- Установка предупреждающих знаков безопасности.
- Применение средств индивидуальной защиты (СИЗ).
- Допуск к работе в опасных зонах только обученного персонала.
- Указание постоянных опасных зон **на стройгенплане** (в ПОС).
