## Вопрос 1. Содержание понятия «Охрана труда»

### Определение
**Охрана труда** — это система обеспечения безопасности здоровья и жизни работающих в сочетании с оптимальной производительностью и комфортностью труда.

### Структура системы охраны труда (рисунок)

```
    ┌─────────────────────────────────────────────┐
    │              ОХРАНА ТРУДА                    │
    ├─────────┬─────────┬──────────┬──────────────┤
    │Правовые │Соц-экон.│Медицинск.│Технические и │
    │ меры    │  меры   │   меры   │организационные│
    ├─────────┼─────────┼──────────┼──────────────┤
    │ТК РФ    │Страхов. │Медосмотры│ПОС, ППР      │
    │Приказы  │Компенс. │Реабилит. │Инструктажи   │
    │Стандарты│Скидки/  │СОУТ      │Средства      │
    │         │надбавки │          │защиты (СИЗ)  │
    └─────────┴─────────┴──────────┴──────────────┘
```

### Объект изучения
Главный объект — **человек в процессе труда**, окружающая производственная среда, взаимодействие с оборудованием, технологией, коллективом.

### Основные задачи
- Расследование причин несчастных случаев и профзаболеваний
- Прогнозирование и выявление опасных и вредных факторов
- Разработка мер по снижению уровня опасностей
- Достижение баланса безопасности и производительности

## Вопрос 4. Задачи современной охраны труда

### Основные задачи
1. Создание объективно безопасной производственной среды
2. Организация санитарно-бытового и лечебного обслуживания
3. Обучение и профессиональная подготовка в области ОТ
4. Информирование работников об условиях труда и рисках
5. Приобретение и выдача СИЗ
6. Проведение специальной оценки условий труда (СОУТ)
7. Расследование и учёт несчастных случаев
8. Компенсация за вредные/опасные условия
9. Обязательное социальное страхование

### Стратегическая цель
Поэтапное приближение к европейскому уровню производственного травматизма. Смертность от производственных причин в России превышает показатели ЕС в **4,5 раза**.

## Вопрос 6. Экономическая оценка последствий несчастных случаев для предприятия

### Методика Г.-У. Гейнриха

### Формула общего ущерба

    У_общ = У_прямые + У_косвенные = У_прямые × (1 + k)

| Источник | Коэффициент k |
|---|---|
| Классика (Гейнрих) | k = 4 |
| Современная (МОТ) | k = 6 |

### Структура убытков (рисунок)

```
    ┌────────────────────────────────────────┐
    │          ОБЩИЙ УЩЕРБ                   │
    ├────────────────┬───────────────────────┤
    │ ПРЯМЫЕ (1)     │ КОСВЕННЫЕ (4–6)       │
    ├────────────────┼───────────────────────┤
    │ Лечение        │ Потери раб. времени   │
    │ Пособия        │ Простои оборудования  │
    │ Страх. выплаты │ Снижение произв-ти   │
    │ Ремонт оборуд. │ Расследование         │
    │ Штрафы         │ Замена работника      │
    │                │ Суд. издержки         │
    │                │ Репутац. потери       │
    └────────────────┴───────────────────────┘
    
    У_общ = У_прям × (1 + 6) = 7 × У_прям
```

## Вопрос 8. Почему экономически выгодны мероприятия по охране труда?

### Экономические механизмы стимулирования

```
    Страховые взносы (ФЗ-125):
    
    Уровень травм. ниже средн.     Уровень травм. выше средн.
    ──────────────────────          ──────────────────────
    Скидка до 40% от тарифа        Надбавка до 40% к тарифу
    
    Экономия от мероприятий по ОТ:
    ┌───────────────────────────────────────┐
    │ Каждый предотвращённый НС экономит   │
    │ предприятию сумму в 5–7 раз больше   │
    │ прямых затрат на мероприятия по ОТ    │
    └───────────────────────────────────────┘
```

### Прямая выгода
1. Снижение убытков от НС (× 5–7 от затрат).
2. Снижение страховых взносов (до −40%).
3. Снижение штрафов.
4. Сокращение потерь рабочего времени.

### Косвенная выгода
5. Повышение производительности.
6. Снижение текучести кадров.
7. Повышение качества продукции.
8. Репутационные преимущества (тендеры).
