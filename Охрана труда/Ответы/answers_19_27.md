## Вопрос 19. Управление профессиональными рисками, цикл Деминга-Шухарта

### Цикл PDCA (рисунок)

```
         ┌────────────────────────┐
         │                        │
    ┌────▼─────┐          ┌───────┴────┐
    │  PLAN    │──────────▶│    DO     │
    │Планируй │          │  Делай    │
    │          │          │           │
    │•Идентиф.│          │•Реализация│
    │ опасност.│          │•Обучение  │
    │•Оценка  │          │•Обеспеч.  │
    │ рисков  │          │ СИЗ       │
    └────▲─────┘          └───────┬────┘
         │                        │
    ┌────┴─────┐          ┌───────▼────┐
    │   ACT   │◀──────────│  CHECK   │
    │ Действуй│          │ Проверяй │
    │          │          │           │
    │•Корректир│          │•Контроль  │
    │•Пересмотр│          │•Мониторинг│
    │ рисков  │          │•Аудит     │
    └──────────┘          └────────────┘
    
    Цикл повторяется непрерывно →
    каждый новый цикл = более высокий
    уровень безопасности!
```

### Нормативная основа
- Приказ Минтруда от 29.10.2021 № 776н — Примерное положение о СУОТ.
- ГОСТ 12.0.230-2007 — ССБТ. Системы управления охраной труда.

## Вопрос 20. Государственный надзор за охраной труда

### Структура надзора (рисунок)

```
    ┌─────────────────────────────────────────────┐
    │       ГОСУДАРСТВЕННЫЙ НАДЗОР ЗА ОТ          │
    ├─────────────┬──────────────┬────────────────┤
    │  РОСТРУД    │ РОСТЕХНАДЗОР │ РОСПОЖНАДЗОР  │
    │(Фед.инспекц)│              │   (МЧС)       │
    │             │              │               │
    │• Проверки   │• Глубокие    │• Горючесть    │
    │• Расследов. │  котлованы   │  материалов   │
    │  НС         │• Краны       │• Огнестойкость│
    │• Предписания│• Сосуды      │  конструкций  │
    │• Штрафы     │  давления    │• Противопож.  │
    │             │• Трубопроводы│  нормы        │
    ├─────────────┴──────────────┴────────────────┤
    │           РОСПОТРЕБНАДЗОР                    │
    │      (санитарно-эпидемиолог. контроль,      │
    │       нормирование ПДК, ПДУ)                │
    └──────────────────────────────────────────────┘
```

### Три функции государственного надзора
1. **Нормотворческая** — разработка нормативных актов
2. **Контрольная** — проверки, наказание, остановка производства
3. **Консультативная** — консультирование работодателей

## Вопрос 21. Ведомственный и общественный надзор за охраной труда

### Структура ведомственного надзора (рисунок)

```
    ┌──────────────────┐
    │   Работодатель   │ ← Персональная ответственность
    └────────┬─────────┘
             │
    ┌────────▼─────────┐
    │ Служба/специалист│ ← Профессиональное
    │   по ОТ          │   сопровождение
    └────────┬─────────┘
             │
    ┌────────▼─────────┐
    │ Руководители     │ ← Непосредственный
    │ среднего звена   │   контроль
    │ (прорабы, мастера)│
    └────────┬─────────┘
             │
    ┌────────▼─────────┐
    │ Комиссия по ОТ   │ ← При числе
    │                  │   работников > 10
    └──────────────────┘
```

### Трёхступенчатый контроль ОТ

| Ступень | Кто проводит | Периодичность |
|---|---|---|
| 1-я | Мастер / прораб | Ежедневно |
| 2-я | Нач. участка + ОТ | Еженедельно |
| 3-я | Комиссия + директор | Ежемесячно |

### Общественный надзор (профсоюзы)
- Участие в расследовании НС
- Экспертиза условий труда
- Обращение в надзорные органы

## Вопрос 22. Обязательное страхование от несчастных случаев

### Схема страхования (рисунок)

```
    ┌──────────────┐     Взносы      ┌────────────────┐
    │ Работодатель │ ───────────────→ │ Фонд соц.     │
    │              │                  │ страхования    │
    └──────────────┘                  └───────┬────────┘
                                              │
                        Выплаты при НС        │
    ┌──────────────┐ ←────────────────────────┘
    │ Пострадавший │
    │ работник     │
    └──────────────┘
    
    32 класса профессионального риска
    Строительство = высокий класс
    
    Стимулирование:
    ▼ травматизм → скидка до 40%
    ▲ травматизм → надбавка до 40%
```

### Нормативная основа
ФЗ от 24.07.1998 № 125-ФЗ «Об обязательном социальном страховании от НС и профзаболеваний».

## Вопрос 23. Виды страхового возмещения ущерба пострадавшему

### Виды выплат (рисунок)

```
    ┌────────────────────────────────────────────┐
    │        СТРАХОВОЕ ВОЗМЕЩЕНИЕ                │
    ├────────────────────────────────────────────┤
    │ 1. Пособие по временной нетрудоспособности│
    │    = 100% от среднего заработка           │
    │    (до выздоровления/установления инвал.) │
    │    → Обязательно                          │
    ├────────────────────────────────────────────┤
    │ 2. Единовременная страховая выплата       │
    │    = по степени утраты трудоспособности   │
    │    (макс. = 60 × МРОТ)                    │
    │    При гибели = 100%                      │
    │    → Обязательно                          │
    ├────────────────────────────────────────────┤
    │ 3. Ежемесячная страховая выплата          │
    │    = % утраты × средняя зарплата          │
    │    → Обязательно                          │
    ├────────────────────────────────────────────┤
    │ 4. Дополнительные расходы на реабилитацию │
    │    (медицинская, социальная, профессион.)  │
    │    → Обоснованность доказывается в суде   │
    └────────────────────────────────────────────┘
```

## Вопрос 24. Как определяется величина страховых взносов?

### Формула страхового взноса

    СВ = ФОТ × Т × K

где: ФОТ — фонд оплаты труда; Т — тариф для данного класса риска; K — коэффициент (скидка/надбавка).

### Тарифы по классам риска (рисунок)

```
    Класс   1        8–12      12–17       32
    Тариф   0,2%     ~1,0%     ~1,3–2,1%   8,5%
    
            │         │           │          │
    Банки ──┘  Жилищное   Строительство  Угольная
               строит.    зданий        промышл.
    
    Скидка/надбавка: ±40% от тарифа
```

### Пример расчёта
ФОТ = 10 000 000 руб./год, строительство (класс 15, тариф 1,7%), скидка 20%:

    СВ = 10 000 000 × 0,017 × 0,8 = 136 000 руб./год

    │ предприятия │         │ государства │

    │             │         │             │
    │    ▓▓▓      │         │ ▓▓▓▓▓▓▓▓▓▓▓│

## Вопрос 27. Три этапа разработки безопасной техники и технологии

### Последовательность этапов (рисунок)

```
    ═══════════════════════════════════════════
    ЭТАП I: ИНТЕГРАЛЬНАЯ безопасность
    ═══════════════════════════════════════════
    Безопасность = неотъемлемая часть технологии
    Без элемента безопасности → процесс 
    НЕ МОЖЕТ осуществляться!
    
    Примеры:
    ┌─────────────────────────────────────────┐
    │ • Выносные опоры крана                  │
    │ • Ключ-марка башенного крана            │
    │ • Блокировка двери лифта                │
    └─────────────────────────────────────────┘
              │ Все возможности исчерпаны?
              ▼ ДА
    ═══════════════════════════════════════════
    ЭТАП II: ДОПОЛНИТЕЛЬНАЯ безопасность
    ═══════════════════════════════════════════
    Дополнительные устройства (не часть технол.)
    ┌─────────────────────────────────────────┐
    │ • Ограждения вращающихся частей         │
    │ • Предохранительные клапаны             │
    │ • Аварийные выключатели                 │
    │ • Защитные козырьки, сетки              │
    └─────────────────────────────────────────┘
              │ Все возможности исчерпаны?
              ▼ ДА
    ═══════════════════════════════════════════
    ЭТАП III: УКАЗАТЕЛЬНАЯ безопасность
    ═══════════════════════════════════════════
    Информационные и организационные меры
    ┌─────────────────────────────────────────┐
    │ • Предупреждающие знаки                 │
    │ • Цветовая маркировка                   │
    │ • Звуковая/световая сигнализация        │
    │ • Инструкции, обучение                  │
    └─────────────────────────────────────────┘
```

### Ключевой принцип
Последовательность **строго обязательна**: сначала I → затем II → в последнюю очередь III. Это обеспечивает приоритет объективного фактора над субъективным.
