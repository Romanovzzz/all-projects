## Вопрос 10. Опасности явного и скрытого состояния, их выявление

### Два состояния опасностей (рисунок)

```
    Аналогия с айсбергом:
    
    ~~~~~~~~~~~~~ Поверхность ~~~~~~~~~~~~~~
           ╱╲             
          ╱  ╲  ← Явные (проявленные)
         ╱    ╲     опасности
        ╱      ╲    (тяжёлые НС)
    ~~~~╱~~~~~~~~╲~~~~~~~~~~~~~~~~~~~~~~~~~
       ╱          ╲
      ╱            ╲ ← Скрытые (латентные)
     ╱              ╲    опасности
    ╱                ╲    (большинство!)
   ╱                  ╲
  ╱                    ╲
 ╱      ОСНОВАНИЕ       ╲
 ───────────────────────── 
```

### Способы выявления
**а) Документальный (ретроспективный):**
- Фиксация ВСЕХ повреждений (включая мелкие)
- Анализ статистики НС и профзаболеваний
- Определение причин

**б) Проактивный (превентивный):**
- Измерение параметров среды (шум, вибрация, пыль)
- Технический осмотр оборудования
- СОУТ (спецоценка условий труда)
- Аудит безопасности

### Проблема российской практики
В строительном комплексе стран ЕС на 1000 работников фиксируется в **28 раз больше** инцидентов, чем в России — не потому, что опаснее, а потому что **налажен учёт**.

## Вопрос 11. Пирамида травматизма Г.-У. Гейнриха

### Пирамида (рисунок)

```
            ╱╲
           ╱  ╲        1 тяжёлая травма
          ╱ 1  ╲       (смерть / тяжёлое
         ╱──────╲       повреждение)
        ╱        ╲
       ╱   29     ╲    29–30 зарегистрированных
      ╱            ╲   НС (средних и лёгких)
     ╱──────────────╲
    ╱                ╲
   ╱      300         ╲  300–330 инцидентов
  ╱                    ╲  без последствий
 ╱──────────────────────╲ (микротравмы, опасные
 ════════════════════════  ситуации)
```

### Пропорция Гейнриха

    1 : 29 : 300

### Главный вывод
Надо **уменьшать основание** пирамиды (массив мелких инцидентов) → автоматически уменьшится вершина (тяжёлые НС). Для этого:
- Регистрировать ВСЕ инциденты
- Анализировать причины КАЖДОГО
- Устранять системные причины

## Вопрос 12. Пять способов защиты человека от опасности

### Способы по убыванию эффективности (рисунок)

```
    Эффективность
    ↑
    █████████████████████ I.  Ликвидация опасности
    ████████████████████  II. Удаление человека
    ██████████████████    III. Экранирование опасности
    ████████████████      IV.  Экранирование человека(СИЗ)
    ██████████████        V.   Обучение персонала
    └──────────────────────────────────────→
                                        Субъективность
```

| Способ | Сущность | Фактор |
|---|---|---|
| I. Ликвидация опасности | Полное устранение | Объективный |
| II. Удаление человека | Автоматизация, дист. управление | Объективный |
| III. Экранирование опасности | Ограждения, блокировки | Частично субъект. |
| IV. Экранирование человека | СИЗ (каски, привязи) | Субъективный |
| V. Обучение | Инструктаж, обучение | Субъективный |

### Формула снижения риска

    R_ост = R_исх × (1 − η₁)(1 − η₂)...(1 − ηₙ)

где R_исх — исходный риск; ηᵢ — эффективность i-го способа защиты (0...1).

## Вопрос 14. Интегрированная, дополнительная и указательная безопасность

### Три этапа (рисунок)

```
    Эффективность
    
    ████████████████████████████  ЭТАП I
    │ ИНТЕГРАЛЬНАЯ безопасность │  Безопасность =
    │ (неотъемлемая часть)      │  часть технологии
    ├───────────────────────────┤
    │                           │
    ████████████████████         ЭТАП II
    │ ДОПОЛНИТЕЛЬНАЯ безоп.    │  Защитные устр-ва
    │ (ограждения, блокировки) │  (дополнение)
    ├──────────────────────────┤
    │                          │
    ████████████████            ЭТАП III
    │ УКАЗАТЕЛЬНАЯ безоп.     │  Знаки, инструкции
    │ (знаки, обучение)       │  (информирование)
    └─────────────────────────┘
    
    Последовательность: I → II → III (строго!)
```

### Примеры
- **Этап I:** Выносные опоры крана (без них кран не работает), ключ-марка, блокировка двери лифта.
- **Этап II:** Ограждения, предохранительные клапаны, аварийные выключатели.
- **Этап III:** Предупреждающие знаки, цветовая маркировка, инструкции, обучение.

## Вопрос 15. Система управления охраной труда, обязанности работодателя

### Обязанности работодателя (10 пунктов)
1. Обеспечение безопасности при эксплуатации зданий, оборудования, технологий
2. Организация санитарно-бытового и лечебно-профилактического обслуживания
3. Обучение безопасным методам труда, проведение инструктажей
4. Приобретение и бесплатная выдача СИЗ
5. Проведение СОУТ
6. Недопущение к работе необученных лиц
7. Расследование и учёт несчастных случаев
8. Организация медицинских осмотров
9. Информирование о рисках
10. Обязательное социальное страхование

### Формула экономической ответственности

    Штраф (ст. 5.27.1 КоАП) = 50 000–80 000 руб. (юр. лицо)
    
    Уголовная ответственность (ст. 143 УК):
    при тяжком вреде здоровью — до 2 лет лишения свободы
    при гибели работника — до 5 лет

## Вопрос 17. Понятие о профессиональном риске

### Формула риска

    R = P × S

где: P — вероятность (частота) опасного события; S — тяжесть последствий.

### Матрица рисков (рисунок)

```
    Тяжесть →  Малая   Средняя  Большая   Критич.
    Вероятн.↓  
    Частая    │ Средн. │ Высок. │ Оч.высок│Оч.высок│
    Вероятная │ Допуст.│ Средн. │ Высок.  │Оч.высок│
    Возможная │ Незнач.│ Допуст.│ Средн.  │ Высок. │
    Редкая    │ Незнач.│ Незнач.│ Допуст. │ Средн. │
```

### Уровни риска и действия
| Уровень | Действия |
|---|---|
| Незначительный | Мониторинг |
| Допустимый | Контроль, наблюдение |
| Средний | Планирование мероприятий |
| Высокий | Немедленные меры |
| Очень высокий | Прекращение работ! |

## Вопрос 18. Способы оценки профессиональных рисков

### Классификация методов (рисунок)

```
    ┌───────────────────────────────────────┐
    │     МЕТОДЫ ОЦЕНКИ РИСКОВ             │
    ├───────────────┬───────────────────────┤
    │ КАЧЕСТВЕННЫЕ  │ КОЛИЧЕСТВЕННЫЕ         │
    ├───────────────┼───────────────────────┤
    │ Матричный     │ Статистический        │
    │ Чек-листы     │ Дерево отказов        │
    │ «Что, если?»  │ Дерево событий        │
    ├───────────────┼───────────────────────┤
    │ ЭКСПЕРТНЫЕ    │                       │
    ├───────────────┤                       │
    │ Метод Дельфи  │                       │
    │ Мозговой штурм│                       │
    └───────────────┴───────────────────────┘
```

### Формулы статистического метода

**Коэффициент частоты:**

    K_ч = (N_нс × 1000) / N_ср

где N_нс — число НС; N_ср — среднесписочная численность.

**Коэффициент тяжести:**

    K_т = D / N_нс

где D — суммарное число дней нетрудоспособности; N_нс — число НС.

**Коэффициент опасности:**

    K_о = K_ч × K_т = (D × 1000) / N_ср

### Пример расчёта
Предприятие: 500 работников, за год — 5 НС, 120 дней нетрудоспособности.

    K_ч = 5×1000 / 500 = 10   (на 1000 работников)
    K_т = 120 / 5 = 24         (дней на 1 НС)
    K_о = 10 × 24 = 240
