## К1. Принцип расчёта деформационных характеристик грунтов по модели Винклера

### Суть модели

Модель Винклера — Фусса (клавишная модель) — простейшая модель грунтового основания, при которой основание представляется **набором независимых пружин**. Коэффициент жёсткости каждой пружины равен коэффициенту постели C₁.

### Схема

```
    ┌════════════════════════════════┐
    │     Фундаментная плита        │
    └══╤══╤══╤══╤══╤══╤══╤══╤══╤══╝
       │  │  │  │  │  │  │  │  │
       ↕  ↕  ↕  ↕  ↕  ↕  ↕  ↕  ↕   ← Пружины
       │  │  │  │  │  │  │  │  │      (независимые!)
    ═══╧══╧══╧══╧══╧══╧══╧══╧══╧═══
              Всегда: S_i = q_i / C₁
              Нет связи между пружинами!
```

### Формулы

**Коэффициент постели (УМП, стр. 9):**

    C₁ = q / S  [кН/м³]

**Осадка методом послойного суммирования (СП 22.13330, п. 5.6.31):**

    S = β · Σ(σ_zp,i · h_i / E_i)

где: β = 0,8 — безразмерный коэффициент; σ_zp,i — среднее вертикальное напряжение от внешней нагрузки в i-м слое грунта, кПа; h_i — толщина i-го слоя грунта (не более 0,4b); E_i — модуль деформации i-го слоя по ветви первичного нагружения, кПа.

*Примечание.* Для фундаментов в котлованах глубиной менее 5 м допускается не учитывать второе слагаемое (разгрузку от собственного веса грунта) — УМП, стр. 11.

**Главный недостаток** — отсутствие учёта распределительной способности основания: осадка точки зависит ТОЛЬКО от нагрузки в этой же точке. Реальные грунты вовлекают в работу примыкающие области.

## К2. Принцип расчёта деформационных характеристик грунтов по модели Пастернака

### Суть модели

Модель Пастернака (двухкоэффициентная модель) учитывает **распределительную способность** основания за счёт добавления нерастяжимой мембраны (коэффициент C₂), связывающей верхние концы пружин (C₁).

### Схема

```
    ┌════════════════════════════════┐
    │     Фундаментная плита        │
    └══╤══╤══╤══╤══╤══╤══╤══╤══╤══╝
       │  │  │  │  │  │  │  │  │
    ═══╬══╬══╬══╬══╬══╬══╬══╬══╬═══ ← Мембрана (C₂)
       ↕  ↕  ↕  ↕  ↕  ↕  ↕  ↕  ↕     (связывает пружины!)
       │  │  │  │  │  │  │  │  │
    ═══╧══╧══╧══╧══╧══╧══╧══╧══╧═══ ← Пружины (C₁)

    Нагрузка в точке А → осадка и в точке B!
    (за счёт мембраны С₂)
```

### Формулы двух коэффициентов постели (УМП, стр. 9–10)

**C₁ (жёсткость пружин):**

    C₁ = E₀ / [H_c · (1 − 2·ν₀²)]

**C₂ (мембранная жёсткость):**

    C₂ = E₀ · H_c / [6 · (1 + ν₀)]

**Усреднённый модуль деформации:**

    E₀ = Σ(σ_zp,ik · h_i) / Σ(σ_zp,ik · h_i / E_i)

**Усреднённый коэффициент Пуассона:**

    ν₀ = Σ(ν_i · h_i) / H_c

где H_c — глубина сжимаемой толщи (определяется по условию σ_zp,i < λ·σ_zg,i, СП 22); ν₀ — усреднённый коэффициент Пуассона.

### Определение H_c

Глубина сжимаемой толщи фиксируется на глубине z_j, начиная с которой выполняется условие:

    σ_zp,i < λ · σ_zg,i

где λ — коэффициент глубины сжимаемой толщи (СП 22.13330.2016).

## К3. Принцип учёта деформационных свойств грунта при расчёте численными методами

### Суть метода последовательных приближений

Расчёт фундамента на упругом основании выполняется итерационно: коэффициенты постели C₁(x,y) и C₂(x,y) уточняются на каждой итерации по результатам расчёта МКЭ.

### Алгоритм (УМП, стр. 11–12)

```
    ┌──────────────────────────────────┐
    │ ШАГ 1: Начальные C₁(x,y), C₂(x,y)│
    │ (по одной из моделей: Пастернак/ │
    │  Винклер / модиф. Пастернак)     │
    └───────────────┬──────────────────┘
                    ▼
    ┌──────────────────────────────────┐
    │ ШАГ 2: Расчёт МКЭ [K]{u}={F}   │
    │ → Контактные давления p(x,y)    │
    └───────────────┬──────────────────┘
                    ▼
    ┌──────────────────────────────────┐
    │ ШАГ 3: Осадки S(x,y)           │
    │ (методом послойного суммирования)│
    │ → C₁(x,y) = p(x,y) / S(x,y)   │
    └───────────────┬──────────────────┘
                    ▼
              Сходимость? ──НЕТ──→ ШАГ 2
                    │
                   ДА
                    ▼
              РЕЗУЛЬТАТ
```

### Критерий сходимости

    |C₁ⁿ⁺¹ − C₁ⁿ| / C₁ⁿ ≤ 5%  (практическая рекомендация — стабилизация между итерациями)

*Примечание.* В нормах конкретный процент не указан — указано «до достижения сходимости по контрольному параметру» (СП 50-101-2004, п. 13.5).

### Модифицированная модель Пастернака (Метод 3 в ПК «Лира»)

Отличие от базовой модели — использование поправочного коэффициента k_i к модулю деформаций E_i. Коэффициент изменяется по закону квадратной параболы:

    k_i(z) = 1 + 11·(z/H_c)²

от k₁ = 1 на уровне подошвы фундамента до k_n = 12 на уровне границы сжимаемой толщи H_c. Основное предположение — модуль деформации грунта увеличивается по глубине.

## К4. Зоны фундаментной плиты, требующие верхнего и нижнего армирования

### Схема распределения моментов

```
    Колонна    Пролёт      Колонна    Пролёт    Колонна
       │←─────────→│         │←────────→│         │
       ▼                     ▼                    ▼
    ═══╬═══════════╬═════════╬══════════╬═════════╬═══
       │           │         │          │         │
    Mx ─╲         ╱─────────╲          ╱─────────╲──
         ╲       ╱            ╲       ╱           ╲
          ╲_   _╱              ╲_   _╱             ╲
            ╲_╱                  ╲_╱
             M(−)                M(−)
                    M(+)                   M(+)

    M(−) под колоннами → ВЕРХНЕЕ армирование (As_в)
    M(+) в пролётах   → НИЖНЕЕ армирование (As_н)
```

### Принцип

- Где момент **отрицательный** (растянута верхняя грань) → верхнее армирование. Это зоны **под колоннами и у стен**.
- Где момент **положительный** (растянута нижняя грань) → нижнее армирование. Это зоны **в пролётах между колоннами**.
- **Фоновое армирование** — у обеих граней по всей площади плиты для выполнения требования μ_s,min ≥ 0,1%.

## К5. Принцип конструкции продольного армирования отдельными стержнями и арматурными сетками

### Два способа армирования

1. **Отдельные стержни** — укладываются в двух направлениях (X и Y) и вяжутся в каркас на месте. Применяются для фундаментных плит.
2. **Арматурные сетки** — заводского изготовления, сварные. Применяются для плит перекрытий.

### Схема армирования

```
    Разрез фундаментной плиты:

    ─── Верхнее армирование ──→    шаг 200 мм
    ════════════════════════════    ∅16 A500C (фон)
    ═ ∅20 дополнит. (под кол.) ═   + ∅20 A500C (доп.)
    ┌──────────────────────────┐
    │                          │
    │     БЕТОН B25            │   h = 1000 мм
    │                          │   h₀ = 940 мм
    │                          │
    └──────────────────────────┘
    ═ ∅20 дополнит. (в пролёте)═   + ∅20 A500C (доп.)
    ════════════════════════════    ∅16 A500C (фон)
    ─── Нижнее армирование ──→     шаг 200 мм

    Защитный слой a₀ ≥ 40 мм (для фундаментов, СП 63 п. 10.3.2)
```

### Конструктивные требования

- Минимальный шаг арматуры: ≥ max(d_max каменного материала + 5 мм; d_s; 25 мм)
- Максимальный шаг: ≤ min(1,5h; 400 мм) — для плит h ≥ 150 мм (СП 63)
- Стандартный шаг: 200 мм (практическая рекомендация)

## К6. Технология расчёта продольного армирования плитной конструкции

### Исходные данные

По результатам статического расчёта МКЭ получены изгибающие моменты M_x, M_y, M_xy во всех конечных элементах фундаментной плиты.

### Формулы расчёта (СП 63.13330.2018)

**Минимальное армирование:**

    μ_s,min = A_s / (b · h₀) × 100% ≥ 0,1%
    A_s,min = 0,001 × b × h₀

**Пример:** b = 1000 мм (полоса 1 м.п.), h₀ = 940 мм:

    A_s,min = 0,001 × 1000 × 940 = 940 мм² = 9,4 см²

**Высота сжатой зоны:**

    x = R_s · A_s / (R_b · b)

**Условие:** x < x_R (граничная высота сжатой зоны — не переармировано).

**Предельный момент:**

    M_ult = γ_b1 · R_b · b · x · (h₀ − x/2)

**Проверка прочности при двухосном изгибе (СП 63, п. 8.1.54):**

    (M_x,ult − M_x)(M_y,ult − M_y) − M²_xy ≥ 0

Дополнительные проверки:

    M_bxy,ult = 0,1·γ_b1·R_b·b²·h ≥ M_xy  (по бетону)
    M_sxy,ult = 0,5·R_s·(A_sx + A_sy)·h₀ ≥ M_xy  (по арматуре)

## К7. Технология расчёта фундаментной плиты по критерию продавливания

### Схема пирамиды продавливания

```
    План (вид сверху):

    ┌─────────────────────────────┐
    │                             │
    │    ┌────────────────────┐   │  ← Расчётный контур
    │    │    0,5·h₀          │   │     (на расст. 0,5h₀
    │    │  ┌──────────┐      │   │      от грани колонны)
    │    │  │ Колонна  │ a×b  │   │
    │    │  │          │      │   │
    │    │  └──────────┘      │   │
    │    │                    │   │
    │    └────────────────────┘   │
    │                             │
    └─────────────────────────────┘

    Разрез:

    ═════════════╦═════════╦═════════════
                 ║Колонна ║
                 ║  a×b   ║
    ─────────────╬─────────╬─────────────  Плита
                ╱          ╲              h₀
    ──────────╱──── 45° ────╲────────────
             ╱                ╲
    ────────╱────── h₀ ────────╲─────────

    Пирамида (угол 45°), высота = h₀
```

### Формулы (СП 63.13330.2018, п. 8.1.46–8.1.49)

**Периметр расчётного контура:**

    u = 2(a + b + 2h₀)

**Момент сопротивления расчётного контура (УМП, стр. 29–30):**

    W_b,x = (a + h₀)/3 · (a + h₀ + b + h₀)
    W_b,y = (b + h₀)/3 · (b + h₀ + a + h₀)

**Условие без поперечной арматуры:**

    F/u + M_x/W_b,x + M_y/W_b,y ≤ γ_b1 · R_bt · h₀

**С поперечным армированием:**

    F/u + M_x/W_b,x + M_y/W_b,y ≤ γ_b1 · R_bt · h₀ + 0,8 · q_sw

    q_sw = R_sw · A_sw / S_w  (интенсивность поперечного армирования, кН/м)

## К8. Принципы раскладки отдельных стержней продольного армирования

### Схема раскладки

```
    ╔════════════════════════════════════════╗
    ║                                        ║
    ║  ─── фоновые ∅16 шаг 200 ──→          ║
    ║  ═══ доп. ∅20 шаг 200 (под кол.) ═══  ║
    ║                                        ║
    ║  ┌──┐         ┌──┐         ┌──┐       ║
    ║  │К1│═════════│К2│═════════│К3│       ║
    ║  └──┘ ← l_доп →└──┘ ← l_доп →└──┘     ║
    ║       ├─ l_an ─┤                       ║
    ║                                        ║
    ╚════════════════════════════════════════╝

    l_доп = зона пиков + 2·l_an (анкеровка с двух сторон)

    Стандартные длины стержней (из прокатной длины 11,7 м):
      11,7/2 = 5,85 м
      11,7/3 = 3,90 м
      11,7/4 = 2,93 м
```

### Требования к стыкам (СП 63, п. 10.3.6)

- В одном сечении стыкуется ≤ 50% рабочей арматуры.
- Разбежка стыков ≥ 1,3·l_l.
- Стержни раскладываются от зон максимальных усилий к краям.

## К9. Взаимная анкеровка стержней (нахлёстка)

### Схема нахлёстки

```
    Стержень 1:    ════════════════╗
                                   ╠═══ l_l ═══╗
    Стержень 2:              ╔═════╝            ║
                             ║                  ║
                        ═════╩══════════════════╝

    ← l_l = α · l₀,an · (A_s,cal / A_s,ef) →
```

### Формулы (СП 63.13330.2018, п. 10.3.5–10.3.6)

**Базовая длина анкеровки:**

    l₀,an = (R_s · A_s) / (R_bond · u_s)

где: R_s — расчётное сопротивление арматуры, МПа; A_s — площадь поперечного сечения стержня, мм²; u_s — периметр стержня, мм; R_bond — сопротивление сцепления.

**Сопротивление сцепления:**

    R_bond = η₁ · η₂ · R_bt

    η₁ = 2,5 (арматура периодического профиля класса A)
    η₂ = 1,0 (d ≤ 32 мм); η₂ = 0,9 (d = 36 мм); η₂ = 0,8 (d = 40 мм)

*Примечание.* В формуле R_bond используется R_bt — расчётное сопротивление бетона осевому растяжению (без дополнительного деления на γ_bt).

**Длина нахлёстки:**

    l_l = α · l₀,an · (A_s,cal / A_s,ef)

    α = 1,2 (растяжение);  α = 0,9 (сжатие)

**Пример (∅16 A500C, B25):**

    R_bt = 1,05 МПа (B25)
    R_bond = 2,5 × 1,0 × 1,05 = 2,625 МПа
    A_s = 201 мм²;  u_s = π·16 = 50,3 мм
    l₀,an = (435 × 201) / (2,625 × 50,3) ≈ 662 мм
    l_l = 1,2 × 662 ≈ 795 мм → принято 800 мм

**Минимальные значения:** не менее 0,4·α·l₀,an; не менее 20·d_s = 320 мм; не менее 250 мм.

## К10. Анкеровка стержней в зоне торца фундаментной плиты

### Схема анкеровки на торце

```
    Торец плиты:

    ┌──────────────────────────────────────┐
    │                                      │
    │     ←── Нижнее армирование ──       │
    │  ════════════════════════╗           │
    │                          ║ ← Отгиб  │
    │                          ║   вверх   │
    │                          ║   l_an    │
    │     ←── Верхнее армирование ──      │
    │  ════════════════════════╗           │
    │                          ║ ← Отгиб  │
    │                          ║   вниз    │
    │                          ║   l_an    │
    └──────────────────────────────────────┘
    ├── Защитный слой ≥ 40 мм ──┤
```

### Формула длины анкеровки (СП 63, п. 10.3.5)

    l_an = α · l₀,an · (A_s,cal / A_s,ef)

    α = 1,0 (прямой стержень, растяжение)
    α = 0,75 (с отгибом на 90°, сжатие)

Если стержень имеет отгиб на 90°, длина анкеровки уменьшается за счёт механического зацепления.

## К11. Анкеровка стержней поперечного армирования (продавливание)

### Схема поперечного армирования

```
    Разрез через зону продавливания:

    ════ Верхняя арматура ═══════════════
    ┌────────────────────────────────────┐
    │   │  │  │  │  │  │  │  │  │  │   │
    │   │  │  │  │  │  │  │  │  │  │   │
    │   │  │  │  │  ╔══╗  │  │  │  │   │
    │   │  │  │  │  ║Кл║  │  │  │  │   │  h₀
    │   │  │  │  │  ╚══╝  │  │  │  │   │
    │   │  │  │  │  │  │  │  │  │  │   │
    │   │  │  │  │  │  │  │  │  │  │   │
    └────────────────────────────────────┘
    ════ Нижняя арматура ════════════════

         ← S_w →  S_w ≤ h₀/3

    ├── 0,5h₀ ──┤──── 1,5h₀ ────┤
    (от грани кол.)

    Первый ряд: на расстоянии ≤ h₀/3 от грани колонны
    Зона установки: ≥ 1,5·h₀ от грани колонны
```

### Требования к анкеровке поперечных стержней

- Стержни должны быть **заведены за верхнюю и нижнюю продольную арматуру** и закреплены крюками или отгибами.
- Шаг S_w ≤ h₀/3 (но не более 300 мм).

### Формула

    q_sw = R_sw · A_sw / S_w  [кН/м]

где: R_sw — расчётное сопротивление поперечной арматуры (A240: R_sw = 170 МПа); A_sw — площадь сечения поперечных стержней в одном ряду; S_w — шаг поперечных стержней.

## К12. Для чего устанавливают фоновое армирование?

### Назначение

1. **Восприятие минимальных изгибающих моментов** — в зонах, где расчётные усилия невелики, но конструкция должна иметь несущую способность.
2. **Ограничение ширины раскрытия трещин** от усадки бетона, температурных деформаций и неравномерной осадки.
3. **Обеспечение пластичности** — нехрупкое разрушение (требование СП 63 к минимальному армированию).
4. **Конструктивный каркас** — для фиксации дополнительных стержней и обеспечения проектного положения арматуры при бетонировании.
5. **Выполнение нормативного требования** μ_s,min ≥ 0,1% (СП 63.13330.2018, п. 10.3.1).

---

## К13. По какому принципу определяется площадь фонового армирования?

### Формула

    μ_s = A_s / (b · h₀) ≥ μ_s,min = 0,1%

    A_s,min = 0,001 × b × h₀  [мм²/м.п.]

### Пример (h = 1000 мм, a₀ = 60 мм → h₀ = 940 мм)

    A_s,min = 0,001 × 1000 × 940 = 940 мм² = 9,4 см²  (на 1 м.п.)

При шаге 200 мм — 5 стержней на 1 м, каждый ≥ 940/5 = 188 мм² → **∅16 A500C** (A = 201 мм²).

    A_s,ef = 5 × 201 = 1005 мм² > 940 мм² ✓

Фоновое армирование устанавливается **у обеих граней** (верхней и нижней) по всей площади плиты.

---

## К14. Что такое нахлёст арматуры и как он определяется?

### Определение

**Нахлёст (нахлёстка)** — способ соединения арматурных стержней без сварки путём их параллельного наложения на длину l_l. Передача усилия между стержнями происходит через бетон за счёт сил сцепления R_bond.

### Формулы (СП 63, п. 10.3.5–10.3.6)

    l_l = α · l₀,an · (A_s,cal / A_s,ef)
    l₀,an = (R_s · A_s) / (R_bond · u_s)
    R_bond = η₁ · η₂ · R_bt

### Минимальные значения

- Не менее 0,4·α·l₀,an
- Не менее 20·d_s
- Не менее 250 мм

### Конструктивные требования

- В одном сечении стыкуется не более 50% рабочей арматуры.
- Разбежка стыков ≥ 1,3·l_l.
- Расстояние в свету между стыкуемыми стержнями ≤ 4·d_s.

## К15. Что такое расчётный контур и пирамида продавливания?

### Определения

**Пирамида продавливания** — конус (усечённая пирамида) разрушения, который образуется в плите при вдавливании колонны. Стенки пирамиды наклонены под углом 45° к горизонту. Высота пирамиды равна h₀.

**Расчётный контур** — замкнутый многоугольник на уровне 0,5·h₀ от грани колонны, ограничивающий зону возможного продавливания.

### Схема

```
    Вид A-A (план на уровне 0,5·h₀):

    ┌────────────────────────────────┐
    │                                │
    │   ┌─────── u_x ──────────┐    │
    │   │                      │    │
    │   │ u_y ┌────────┐       │    │
    │   │     │Колонна │ a × b │    │
    │   │     │        │       │    │
    │   │     └────────┘       │    │
    │   │                      │    │
    │   └──────────────────────┘    │
    │                                │
    │   u_x = a + 2·(0,5·h₀) = a + h₀  │
    │   u_y = b + 2·(0,5·h₀) = b + h₀  │
    └────────────────────────────────┘
```

### Формулы

    u = 2(u_x + u_y) = 2(a + b + 2h₀)

Для **кр6х/угловых колонн** контур может быть **незамкнутым** (обрезается по краю плиты).

    F/u + M_x/W_b,x + M_y/W_b,y ≤ γ_b1 · R_bt · h₀

### 1.5. Основные положения расчёта МКЭ

### Суть метода

Метод конечных элементов (МКЭ) — численный метод решения задач строительной механики. Непрерывная конструкция разбивается на конечные элементы (КЭ), связанные в узлах.

### Типы конечных элементов

| Тип КЭ | Применение | Пример |
|---|---|---|
| Стержневой | Балки, колонны | 2 узла, 6 DOF каждый |
| Пластинчатый (оболочечный) | Плиты, стены | 3–4 узла |
| Объёмный | Грунт, массивы | 4–8 узлов |

### Уравнение МКЭ

    [K]{u} = {F}

где: [K] — глобальная матрица жёсткости; {u} — вектор перемещений узлов (неизвестные); {F} — вектор узловых нагрузок (известные).

**Требования к сетке:**
- Размер КЭ ≤ l/6 (l = пролёт)
- Сгущение сетки у колонн и в зонах концентрации напряжений
- Соотношение сторон КЭ не более 1:2

```

4. **Деформационная модель** (СП 63, п. 8.1.20–8.1.30) — для расчёта предельных состояний по нелинейной деформационной модели.

```

### 2.3. Принципы расчёта висячих покрытий

**Усилие в тросе (для параболической формы):**

    T = q·L² / (8·f)

где: q — распределённая нагрузка; L — пролёт; f — стрела провисания.

**Расчёт включает:**
- Определение формы провисания (цепная линия / парабола)
- Учёт продольной деформации тросов (удлинение)
- Расчёт опорного контура на сжатие (распор)
- Учёт аэродинамической неустойчивости (отрицательное давление ветра)
- Геометрически нелинейный расчёт (большие перемещения)

### 2.4. Конструирование пространственных составных элементов

- **Узлы:** сварка закладных, выпуски арматуры, замоноличивание стыков
- **Рёбра жёсткости:** утолщения на краях панелей для повышения устойчивости
- **Предварительное напряжение:** при больших пролётах для контроля трещин
- **Диафрагмы:** предотвращение выпучивания тонкостенных элементов
- **Шпоночные соединения:** для передачи сдвигающих усилий между панелями

### 3.4. Определение ветровой нагрузки на дымовые трубы

**Формула (СП 20.13330.2016, раздел 11):**

    w = w₀ · k(z) · c  [кПа]

| Параметр | Значение |
|---|---|
| w₀ | Нормативное давление для ветрового района (табл. 11.1) |
| k(z) | Коэффициент по высоте (зависит от типа местности A/B/C) |
| c | Аэродинамический коэффициент (~0,6 для гладкого цилиндра при Re > 4·10⁵) |

**Динамическая составляющая** — пульсационная нагрузка, учитываемая через коэффициент динамичности ξ и коэффициент пространственной корреляции ν.

*Примечание:* для дымовых труб переменного сечения c зависит от числа Рейнольдса и шероховатости поверхности.

### 3.5. Фундаменты дымовых труб

Обычно — **кольцевой фундамент** (плита с центральным отверстием).

**Краевые давления:**

    p_max = N/A + M/W
    p_min = N/A − M/W

**Условие:** p_min ≥ 0 (отсутствие отрыва подошвы).

```
    Эпюра давлений:

    ┌────────────────────────┐
    │ p_max                 p_min│
    │ ████████████████      ████│
    │ ████████████████████  ████│
    └────────────────────────┘

    p_min ≥ 0 → нет отрыва ✓
```

Для высоких труб M от ветра может потребовать устройства сваного основания.

### 5.1. Работа каменной кладки при местном сжатии

### Эффект обоймы

```
    ┌────────────────────────────────┐
    │     Ненагруженная кладка      │
    │                               │
    │   ┌───────────────┐           │
    │   │ ███ Нагрузка ███│         │
    │   │ ███    q      ███│← A_c   │
    │   │ ███           ███│         │
    │   └───────────────┘           │
    │ ←──── Обойма ────→           │
    │   (ограничение               │
    │    поперечных деформаций)     │← A (расчётная)
    └────────────────────────────────┘
```

**Формула (СП 15.13330.2020):**

    R_c = ψ · R · √(A / A_c)

где: R — расчётное сопротивление кладки сжатию; A — расчётная площадь сечения; A_c — площадь приложения нагрузки; ψ — коэффициент полноты эпюры давлений (ψ = 1 для равномерной, ψ = 0,75 для треугольной).

**Ограничение:** √(A/A_c) ≤ 1,5 (для кладки из полнотелого кирпича) — 2,0 (для кладки из бетонных блоков).

### 6.3. Выбор метода усиления. Исходные данные

    Перегрузка = (M − M_u) / M_u × 100%

где M — действующий момент; M_u — несущая способность.

**Исходные данные для проектирования:**

4. Условия эксплуатации (нагрузки, среда, температура)

**Критерии выбора метода:** процент перегрузки, доступность конструкции, условия производства работ, стоимость, срок службы.

### Формула несущей способности ЖБ обоймы

    N_u = φ · [η·(R_b·A_b + R_sc·A_s) + γ_cn·(R_fb·A_bs + R_ss·A_ss)]

где: γ_cn = 1,0 (полная обойма, контакт со всех сторон); γ_cn = 0,7 (контакт только по 2 сторонам).

---

### 6.5. Методы усиления каменных конструкций

```
    ╔══════════════════════╗
    ║ Уголок ╔══════╗ Уголок║
    ║ ┌─────┐║Кладка║┌─────┐║
    ║ │     │║      ║│     │║
    ║ │     │╠══════╣│     │║← Планки-связи
    ║ │     │║      ║│     │║   (шаг ≤ 500 мм)
    ║ │     │╠══════╣│     │║
    ║ └─────┘║      ║└─────┘║
    ║        ╚══════╝       ║
    ╚══════════════════════╝

    Увеличение несущей способности:
    Стальная обойма: на 50–100%
    ЖБ обойма: на 100–200%
```

**Формула стальной обоймы (СП 15):**

    N_u = m_g · R · A · (1 + 2·μ·R_s,c·η / R)

где: m_g — коэффициент продольного изгиба; μ — процент армирования обоймой; η — коэффициент условий работы; R — расчётное сопротивление кладки.

    │           ╱╱                  │

| Полимерцементный | — | 0,5–1 мм | Прочность до 90–95% |
| Эпоксидный | — | 0,1–0,5 мм | Прочность до 100% |

|---|---|---|---|---|

### Формы выпуска

1. **Ткани** (CarbonWrap Tape) — t = 0,129–0,294 мм, пропитка эпоксидной смолой на месте
2. **Ламели** (CarbonWrap Lamel) — t = 1,4–5 мм, готовые полосы заводского изготовления
3. **Стержни** — замена стальной арматуры (стеклопластиковая, базальтопластиковая)
4. **Сетки** — усиление каменных конструкций

### Применение

- **Для изгиба:** ленты внизу балки (растянутая зона)
- **Для среза:** U-образные ленты на боковых гранях
- **Для сжатия:** обмотка колонн (эффект обоймы)

### 7.5. Права и обязанности технадзора заказчика

**Обязанности:**

1. Проверка документов качества (сертификатов, паспортов) на материалы и изделия
2. Контроль соблюдения проектных решений и требований нормативных документов
3. Участие в освидетельствовании скрытых работ и составлении актов
4. Контроль устранения дефектов, выявленных при приёмке
5. Проверка объёмов выполненных работ
6. Ведение журнала технадзора и журнала работ
7. Контроль ведения исполнительной документации подрядчиком

**Права:**

1. Беспрепятственный доступ к объекту строительства
2. Приостановление работ при выявлении нарушений
3. Требование проведения дополнительных испытаний
4. Требование переделки работ, не соответствующих проекту
5. Отказ от подписания актов приёмки при наличии нарушений

---

### 7.6. Права и обязанности авторского надзора

**Обязанности:**

1. Выборочная проверка соответствия выполняемых работ проектной документации
2. Контроль качества и геометрической точности СМР
3. Информирование заказчика о выявленных нарушениях
4. Внесение записей в журнал авторского надзора
5. Согласование или отклонение предложений по изменению проектных решений
6. Участие в приёмке ответственных конструкций и скрытых работ

**Права:**

1. Доступ к объекту строительства
2. Запрос и получение исполнительной документации
3. Приостановление работ (через заказчика) при обнаружении отступлений от проекта
4. Внесение изменений в проектную и рабочую документацию
5. Контроль выполнения ранее выданных предписаний

### Журнал авторского надзора

Фиксирует: дату посещения; обнаруженные отступления от проекта; выданные предписания; сроки устранения; отметку о фактическом выполнении.
