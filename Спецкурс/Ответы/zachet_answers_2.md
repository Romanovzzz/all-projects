### 4.1. Виды динамических воздействий

### Классификация (рисунок)

```
    ┌──────────────────────────────────────────┐
    │       ДИНАМИЧЕСКИЕ ВОЗДЕЙСТВИЯ           │
    ├──────────────┬───────────────────────────┤
    │ УДАРНЫЕ      │ Падение груза, взрыв,     │
    │ (импульсные) │ столкновение              │
    ├──────────────┼───────────────────────────┤
    │ ВИБРАЦИОННЫЕ │ Оборудование (прессы,     │
    │ (периодич.)  │ молоты, компрессоры)      │
    ├──────────────┼───────────────────────────┤
    │ СЕЙСМИЧЕСКИЕ │ Землетрясения             │
    │              │ (спектр ускорений)        │
    ├──────────────┼───────────────────────────┤
    │ ВЕТРОВЫЕ     │ Пульсации скорости ветра  │
    │ ПУЛЬСАЦИИ    │                           │
    ├──────────────┼───────────────────────────┤
    │ ВИХРЕВОЕ     │ Отрыв вихрей от цилиндр.  │
    │ ВОЗБУЖДЕНИЕ  │ конструкций (трубы, мачты)│
    └──────────────┴───────────────────────────┘
```

### Формулы

**Инерционная сила:**

    F_ин = m · a  [кН]

**Условие резонанса (опасно!):**

    f_нагр ≈ f_собств  → резкий рост амплитуд

**Динамический коэффициент:**

    K_д = 1 / |1 − (ω/ω₀)²|

где ω — частота вынужденных колебаний; ω₀ — собственная частота.

### 4.2. Работа ЖБК при повышенных и высоких температурах

### Снижение прочности (рисунок)

```
    R_b / R_b(20°C)
    ↑
    1,0 ████████████████████████
    0,8 █████████████████████
    0,6 ████████████████
    0,4 ████████████
    0,2 ██████
    0   ██
    └──────┬──────┬──────┬──────┬──→ T, °C
          100    300    500    700
    
    100–200°C: удаление влаги, усадочные трещины
    300–500°C: снижение R_b на 20–50%
    500–700°C: разложение Ca(OH)₂
    > 700°C:   полное разрушение
```

### Меры защиты
- Увеличение защитного слоя до 40–60 мм
- Жаростойкие бетоны (глинозёмистый цемент)
- Жаростойкая арматура (А240, А400)
- Теплоизоляционные экраны, футеровка
- Температурные швы

### 4.3. Работа ЖБК при низких отрицательных температурах

### Механизм разрушения (рисунок)

```
    Цикл замораживания–оттаивания:
    
    Вода в порах      Замерзание         Оттаивание
    ┌─────┐           ┌─────┐            ┌─────┐
    │ . . │   →→→    │ ╳ ╳ │  →→→       │ ╳ . │
    │ . . │           │ ╳ ╳ │ +9% объём  │ . ╳ │
    │ . . │           │ ╳ ╳ │            │ . . │
    └─────┘           └─────┘            └─────┘
                      Микротрещины!       Прогрессир.
                                          разрушение
    
    Решение: морозостойкие бетоны F150–F300
             + воздухововлекающие добавки
```

### Требования
- Марка морозостойкости F150–F300
- Арматура A500С, А400 (не термоупрочнённая!)
- Увеличение защитного слоя

### 4.4. Виды агрессивных сред

### Классификация (рисунок)

```
    ┌──────────────────────────────────────────┐
    │          АГРЕССИВНЫЕ СРЕДЫ               │
    ├────────────┬─────────────────────────────┤
    │ Газообразные│ CO₂, SO₂, H₂S, Cl₂, NH₃  │
    │            │ → Карбонизация              │
    ├────────────┼─────────────────────────────┤
    │ Жидкие     │ Кислоты, щёлочи, соли,     │
    │            │ нефтепродукты               │
    │            │ → Растворение цемент. камня │
    ├────────────┼─────────────────────────────┤
    │ Твёрдые    │ Соли при увлажнении         │
    │            │ → Кристаллизация в порах    │
    ├────────────┼─────────────────────────────┤
    │ Биологич.  │ Бактерии, грибки, плесень   │
    │            │ → Продукты жизнедеятельности│
    └────────────┴─────────────────────────────┘
```

### Три рода коррозии бетона
- **I род** — выщелачивание (растворение)
- **II род** — обменные реакции
- **III род** — кристаллизация новообразований

### Степени агрессивности (СП 28.13330)
| Степень | Время разрушения |
|---|---|
| Слабая | Десятки лет |
| Средняя | 10–25 лет |
| Сильная | Быстрое |

## РАЗДЕЛ 5. Каменные и армокаменные конструкции

### 5.1. Работа каменной кладки при местном сжатии

### Эффект обоймы (рисунок)

```
    ┌────────────────────────────────┐
    │     Ненагруженная кладка      │
    │                               │
    │   ┌───────────────┐           │
    │   │ ███ Нагрузка ███│         │
    │   │ ███    q      ███│← A_c   │
    │   │ ███           ███│         │
    │   └───────────────┘           │
    │ ←──── Обойма ────→           │
    │   (ограничение               │
    │    поперечных деформаций)     │← A (расчётная)
    └────────────────────────────────┘
    
    R_c = ψ · R · √(A / A_c) > R  !!!
    (прочность ВЫШЕ за счёт обоймы)
```

### Формула

    R_c = ψ · R · √(A / A_c)

где: R — расчётное сопротивление кладки; A — расчётная площадь; A_c — площадь нагрузки; ψ — коэффициент полноты эпюры.

Ограничение: √(A/A_c) ≤ 1,5–2,0.

### 5.3. Расчёты по 2-й группе ПС

### Формулы

**Момент трещинообразования:**

    M_crc = R_bt · W

**Условие отсутствия раскрытия швов:**

    e₀ ≤ y = h/6  (для прямоугольного сечения)

**Прогиб:**

    f/l ≤ 1/200...1/500  (зависит от типа стены)

### 5.5. Пространственная работа зданий с каменной кладкой

### Схема пространственной жёсткости (рисунок)

```
    План здания:
    
    ╔═══════╦═══════╦═══════╗
    ║       ║       ║       ║ ← Продольные стены
    ║       ║       ║       ║
    ╠═══════╬═══════╬═══════╣ ← Поперечные стены
    ║       ║       ║       ║    (диафрагмы)
    ║       ║       ║       ║
    ╠═══════╬═══════╬═══════╣ ← Перекрытия
    ║       ║       ║       ║    (горизонтальные диски)
    ║       ║       ║       ║
    ╚═══════╩═══════╩═══════╝
    
    Ветер →→→ 
    Передача: стены → перекрытия → поперечные стены
                      (диски)        (диафрагмы)
```

### Элементы пространственной жёсткости
1. Поперечные стены (диафрагмы)
2. Перекрытия (горизонтальные диски)
3. Армированные пояса (ЖБ, по верху стен)
4. Анкерные связи (стены ↔ перекрытия)
