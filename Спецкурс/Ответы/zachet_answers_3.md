### 6.1. Понятие о надёжности зданий и сооружений

### Составляющие надёжности (рисунок)

```
    ┌──────────────────────────────────────┐
    │            НАДЁЖНОСТЬ                 │
    ├────────────┬──────────┬──────────────┤
    │ Безотказ-  │ Долго-   │ Ремонто-     │
    │ ность      │ вечность │ пригодность  │
    ├────────────┼──────────┼──────────────┤
    │Работоспосо-│Сохранение│Приспособлен- │
    │бность без  │работосп. │ность к обнар.│
    │перерывов   │до предел.│и устранению  │
    │            │состояния │отказов       │
    └────────────┴──────────┴──────────────┘
```

### Формула расчёта по предельным состояниям

    γ_f · S_n ≤ R_n / (γ_m · γ_n)

где: γ_f — коэффициент надёжности по нагрузке; S_n — нормативное воздействие; R_n — нормативное сопротивление; γ_m — коэффициент по материалу; γ_n — коэффициент по ответственности.

| Уровень ответственности | γ_n |
|---|---|
| Повышенный | 1,0–1,1 |
| Нормальный | 1,0 |
| Пониженный | 0,8–0,95 |

    Перегрузка = (M − M_u) / M × 100%

где M — действующий момент; M_u — несущая способность.

### 6.4. Методы усиления ЖБК

### Сравнение методов (рисунок)

```
    ┌──────────────────────────────────────────────┐
    │           МЕТОДЫ УСИЛЕНИЯ ЖБК                │
    ├──────────────┬───────────────────────────────┤
    │ Набетонка    │ Увеличение сечения            │
    │ (наращивание)│ + доп. арматура               │
    ├──────────────┼───────────────────────────────┤
    │ ЖБ обойма    │ Охватывает элемент            │
    │              │ со всех сторон                │
    ├──────────────┼───────────────────────────────┤
    │ Стальная     │ Уголки по рёбрам +            │
    │ обойма       │ планки-связи                  │
    ├──────────────┼───────────────────────────────┤
    │ Композиты    │ Углеволокно (FRP)             │
    │ (FRP)        │ → Лёгкий, коррозионностойкий  │
    ├──────────────┼───────────────────────────────┤
    │ Доп. опоры   │ Подведение балок, стоек,      │
    │ и шпренгели  │ разгружающих конструкций      │
    ├──────────────┼───────────────────────────────┤
    │ Предвар.     │ Внешние тяжи                  │
    │ напряжение   │ (создание разгрузки)          │
    └──────────────┴───────────────────────────────┘
```

### Схема усиления колонны ЖБ обоймой (рисунок)

```
    Поперечное сечение:
    
    ┌──────────────────────┐
    │ Новый бетон (обойма) │
    │  ┌──────────────┐    │
    │  │ Существующий │    │
    │  │   бетон       │    │
    │  │   ╬════╬     │    │
    │  │   ║    ║     │    │ ← Новая арматура
    │  │   ╬════╬     │    │    по периметру
    │  └──────────────┘    │
    └──────────────────────┘
    
    Хомуты (поперечная арматура): ∅8, шаг ≤ 200 мм
```

### Формула несущей способности ЖБ обоймы

    N_u = φ · [η·(R_b·A_b + R_sc·A_s) + γ_cn·(R_fb·A_bs + R_ss·A_ss)]

где γ_cn = 0,7–1,0 — коэффициент условий работы обоймы.

### 6.5. Методы усиления каменных конструкций

### Схема стальной обоймы (рисунок)

```
    ╔══════════════════════╗
    ║ Уголок ╔══════╗ Уголок║
    ║ ┌─────┐║Кладка║┌─────┐║
    ║ │     │║      ║│     │║
    ║ │     │╠══════╣│     │║← Планки-связи
    ║ │     │║      ║│     │║   (шаг ≤ 500 мм)
    ║ │     │╠══════╣│     │║
    ║ │     │║      ║│     │║
    ║ └─────┘║      ║└─────┘║
    ║        ╚══════╝       ║
    ╚══════════════════════╝
    
    Увеличение несущей способности:
    на 50–100% (стальная)
    на 100–200% (ЖБ обойма)
```

### Формула стальной обоймы

    N_u = m_g · R · A · (1 + 2μ/R · R_s,c · η)

### 6.6. Инъецирование каменной кладки

### Технология (рисунок)

```
    Разрез стены с трещиной:
    
    ┌────────────────────────────────┐
    │ Кладка     ╱╱ Трещина         │
    │           ╱╱                  │
    │ ● ──────╱╱──── ●  ← Пакеры   │
    │        ╱╱         (инъекторы) │
    │ ● ───╱╱─────── ●             │
    │     ╱╱                       │
    │ ● ╱╱────────── ●             │
    │  ╱╱                          │
    └────────────────────────────────┘
    
    ● = пакер (шаг 500–1000 мм)
    
    Давление: 0,1–0,6 МПа
    Направление: снизу → вверх
    
    Результат: прочность до 80–90%
    от первоначальной
```

### Составы
- Цементно-песчаные (В/Ц = 0,5–0,7)
- Полимерцементные (+ эпоксидные смолы)
- Эпоксидные (для тонких трещин 0,1–0,5 мм)

### 6.7. Виды композитных материалов (FRP)

### Сравнение волокон

| Тип | E, ГПа | σ, МПа | ρ, г/см³ | ε, % |
|---|---|---|---|---|
| Углеволокно (ВП) | 240–280 | 4100–5100 | 1,75 | 1,6–1,7 |
| Углеволокно (ВМ) | 390–760 | 2400–3400 | 1,85 | 0,5–0,8 |
| Стекловолокно | 85–90 | 3500–4800 | 2,46 | 4,5–5,5 |
| Арамидное | 62–180 | 3600–3800 | 1,44 | 1,9–5,5 |

### Схема усиления балки FRP (рисунок)

```
    ┌───────────────────────────────────┐
    │         Сжатая зона               │
    │                                   │
    │     Бетон                         │
    │                                   │
    │         Растянутая зона           │
    │ ═══════ Стальная арматура ═══════ │
    └───────────────────────────────────┘
    ▓▓▓▓▓▓▓ FRP ленты / ламели ▓▓▓▓▓▓▓▓  ← Наклейка
    
    Для ИЗГИБА: ленты внизу (растянутая зона)
    Для СРЕЗА:  U-образные ленты на боках
    Для СЖАТИЯ: обмотка колонны
```

### Формы выпуска
1. **Ткани** (CarbonWrap Tape) — t = 0,129–0,294 мм, пропитка на месте
2. **Ламели** (CarbonWrap Lamel) — t = 1,4–5 мм, готовые полосы
3. **Стержни** — замена стальной арматуры
4. **Сетки** — усиление каменных конструкций

### 7.5. Права и обязанности технадзора заказчика

**Обязанности:**
1. Проверка документов качества на материалы
2. Контроль соблюдения проектных решений
3. Участие в освидетельствовании скрытых работ
4. Контроль устранения дефектов
5. Проверка объёмов работ
6. Ведение журнала технадзора
7. Контроль исполнительной документации

**Права:**
1. Беспрепятственный доступ к объекту
2. Приостановление работ
3. Требование доп. испытаний
4. Требование переделки
5. Отказ от подписи актов приёмки

---

### 7.6. Права и обязанности авторского надзора

**Обязанности:**
1. Выборочная проверка соответствия проекту
2. Контроль качества и точности СМР
3. Информирование заказчика о нарушениях
4. Записи в журнал авторского надзора
5. Согласование/отклонение изменений
6. Участие в приёмке ответственных конструкций

**Права:**
1. Доступ к объекту
2. Запрос исполнительной документации
3. Приостановление работ (через заказчика)
4. Внесение изменений в проект
5. Контроль выполнения предписаний

### Журнал авторского надзора
Фиксирует: дату, обнаруженные отступления, предписания, сроки устранения, отметку о выполнении.
