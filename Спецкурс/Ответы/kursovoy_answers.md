# Ответы на вопросы к защите курсового проекта

## 1. Принцип расчета деформационных характеристик грунтов по модели Винклера

### Схема модели Винклера (рисунок)

```
    ┌════════════════════════════════┐
    │     Фундаментная плита        │
    └══╤══╤══╤══╤══╤══╤══╤══╤══╤══╝
       │  │  │  │  │  │  │  │  │
       ↕  ↕  ↕  ↕  ↕  ↕  ↕  ↕  ↕   ← Пружины
       │  │  │  │  │  │  │  │  │      (независимые!)
    ═══╧══╧══╧══╧══╧══╧══╧══╧══╧═══
              Всегда: S_i = q_i / C₁
              Нет связи между пружинами!
```

### Основные формулы

**Коэффициент постели:**

    C₁ = q / S  [кН/м³]

**Осадка методом послойного суммирования (СП 22.13330):**

    S = β · Σ(σ_zp,i · h_i / E_i)

где: β = 0,8; σ_zp,i — напряжение в i-м слое; h_i — толщина слоя; E_i — модуль деформации.

**Главный недостаток** — нет учёта распределительной способности: осадка точки зависит ТОЛЬКО от нагрузки в этой точке.

## 2. Принцип расчета деформационных характеристик грунтов по модели Пастернака

### Схема модели Пастернака (рисунок)

```
    ┌════════════════════════════════┐
    │     Фундаментная плита        │
    └══╤══╤══╤══╤══╤══╤══╤══╤══╤══╝
       │  │  │  │  │  │  │  │  │
    ═══╬══╬══╬══╬══╬══╬══╬══╬══╬═══ ← Мембрана (C₂)
       ↕  ↕  ↕  ↕  ↕  ↕  ↕  ↕  ↕     (связывает пружины!)
       │  │  │  │  │  │  │  │  │
    ═══╧══╧══╧══╧══╧══╧══╧══╧══╧═══ ← Пружины (C₁)
    
    Нагрузка в точке А → осадка и в точке B!
    (за счёт мембраны С₂)
```

### Формулы двух коэффициентов постели

**C₁ (жёсткость пружин):**

    C₁ = E₀ / [H_c · (1 − 2ν₀²)]

**C₂ (мембранная жёсткость):**

    C₂ = E₀ · H_c / [6 · (1 + ν₀)]

**Усреднённый модуль деформации:**

    E₀ = Σ(σ_zp,ik · h_i) / Σ(σ_zp,ik · h_i / E_i)

где H_c — глубина сжимаемой толщи; ν₀ — коэффициент Пуассона.

## 3. Принцип учёта деформационных свойств грунта при расчёте численными методами

### Итерационный метод (рисунок)

```
    ┌──────────────────────────────────┐
    │ ШАГ 1: Начальные C₁(x,y), C₂(x,y)│
    └───────────────┬──────────────────┘
                    ▼
    ┌──────────────────────────────────┐
    │ ШАГ 2: Расчёт МКЭ [K]{u}={F}   │
    │ → Контактные давления p(x,y)    │
    └───────────────┬──────────────────┘
                    ▼
    ┌──────────────────────────────────┐
    │ ШАГ 3: Осадки S(x,y)           │
    │ → C₁(x,y) = p(x,y) / S(x,y)   │
    └───────────────┬──────────────────┘
                    ▼
              Сходимость? ──НЕТ──→ ШАГ 2
                    │
                   ДА
                    ▼
              РЕЗУЛЬТАТ
```

### Критерий сходимости

    |C₁ⁿ⁺¹ − C₁ⁿ| / C₁ⁿ ≤ 5%  (стабилизация между итерациями)

## 4. Зоны фундаментной плиты, требующие верхнего и нижнего армирования

### Схема распределения моментов (рисунок)

```
    Колонна    Пролёт      Колонна    Пролёт    Колонна
       │←─────────→│         │←────────→│         │
       ▼                     ▼                    ▼
    ═══╬═══════════╬═════════╬══════════╬═════════╬═══
       │           │         │          │         │
    Mx ─╲         ╱─────────╲          ╱─────────╲──
         ╲       ╱            ╲       ╱           ╲
          ╲_   _╱              ╲_   _╱             ╲
            ╲_╱                  ╲_╱
             M(−)                M(−)
                    M(+)                   M(+)
    
    M(−) под колоннами → ВЕРХНЕЕ армирование (As_в)
    M(+) в пролётах   → НИЖНЕЕ армирование (As_н)
```

### Принцип
- Где момент **отрицательный** (растянута верхняя грань) → верхнее армирование.
- Где момент **положительный** (растянута нижняя грань) → нижнее армирование.
- Фоновое армирование — у обеих граней по всей площади.

## 5. Принцип конструкции продольного армирования

### Схема армирования (рисунок)

```
    Разрез фундаментной плиты:

    ─── Верхнее армирование ──→    шаг 200 мм
    ════════════════════════════    ∅16 A500C (фон)
    ═ ∅20 дополнит. (под кол.) ═   + ∅20 A500C (доп.)
    ┌──────────────────────────┐
    │                          │
    │     БЕТОН B25            │   h = 1000 мм
    │                          │   h₀ = 940 мм
    │                          │
    └──────────────────────────┘
    ═ ∅20 дополнит. (в пролёте)═   + ∅20 A500C (доп.)
    ════════════════════════════    ∅16 A500C (фон)
    ─── Нижнее армирование ──→     шаг 200 мм
    
    Защитный слой a₀ ≥ 40 мм (фундаменты)
```

---

## 6. Технология расчёта продольного армирования плитной конструкции

### Формулы расчёта

**Минимальное армирование:**

    μ_s,min = A_s / (b · h₀) × 100% ≥ 0,1%
    A_s,min = 0,001 × b × h₀

**Пример:** b = 1000 мм, h₀ = 940 мм:

    A_s,min = 0,001 × 1000 × 940 = 940 мм² = 9,4 см²

**Проверка прочности (СП 63.13330, п. 8.1.54):**

    (M_x,ult − M_x)(M_y,ult − M_y) − M²_xy ≥ 0

**Предельный момент:**

    M_ult = γ_b1 · R_b · b · x · (h₀ − x/2)

**Высота сжатой зоны:**

    x = R_s · A_s / (R_b · b)

**Условие:** x < x_R (не переармировано).

## 7. Технология расчёта по критерию продавливания

### Схема пирамиды продавливания (рисунок)

```
    План (вид сверху):
    
    ┌─────────────────────────────┐
    │                             │
    │    ┌────────────────────┐   │  ← Расчётный контур
    │    │    0,5·h₀          │   │     (на расст. 0,5h₀
    │    │  ┌──────────┐      │   │      от грани колонны)
    │    │  │ Колонна  │ a×b  │   │
    │    │  │          │      │   │
    │    │  └──────────┘      │   │
    │    │                    │   │
    │    └────────────────────┘   │
    │                             │
    └─────────────────────────────┘
    
    Разрез:
    
    ═════════════╦═════════╦═════════════
                 ║Колонна ║
                 ║  a×b   ║
    ─────────────╬─────────╬─────────────  Плита
                ╱          ╲              h₀
    ──────────╱──── 45° ────╲────────────
             ╱                ╲
    ────────╱────── h₀ ────────╲─────────
    
    Пирамида (угол 45°), высота = h₀
```

### Формулы

**Периметр расчётного контура:**

    u = 2(a + b + 2h₀)

**Условие без поперечной арматуры:**

    F/u ≤ γ_b1 · R_bt · h₀

**С учётом моментов:**

    F/u + M_x/W_b,x + M_y/W_b,y ≤ γ_b1 · R_bt · h₀

**С поперечным армированием:**

    F/u + M/W ≤ γ_b1 · R_bt · h₀ + 0,8 · q_sw

    q_sw = R_sw · A_sw / S_w  (интенсивность поперечного армирования)

## 8. Принципы раскладки отдельных стержней

### Схема раскладки (рисунок)

```
    ╔════════════════════════════════════════╗
    ║                                        ║
    ║  ─── фоновые ∅16 шаг 200 ──→          ║
    ║  ═══ доп. ∅20 шаг 200 (под кол.) ═══  ║
    ║                                        ║
    ║  ┌──┐         ┌──┐         ┌──┐       ║
    ║  │К1│═════════│К2│═════════│К3│       ║
    ║  └──┘ ← l_доп →└──┘ ← l_доп →└──┘     ║
    ║       ├─ l_an ─┤                       ║
    ║                                        ║
    ╚════════════════════════════════════════╝
    
    l_доп = зона пиков + 2·l_an (анкеровка)
    
    Стандартные длины: 11,7/2 = 5,85 м
                       11,7/3 = 3,90 м
                       11,7/4 = 2,93 м
```

### Требования к стыкам
- В одном сечении ≤ 50% рабочей арматуры.
- Разбежка стыков ≥ 1,3·l_l.

## 9. Взаимная анкеровка стержней (нахлёстка)

### Схема нахлёстки (рисунок)

```
    Стержень 1:    ════════════════╗
                                   ╠═══ l_l ═══╗
    Стержень 2:              ╔═════╝            ║
                             ║                  ║
                        ═════╩══════════════════╝
    
    ← l_l = α · l₀,an · (A_s,cal / A_s,ef) →
```

### Формулы

**Базовая длина анкеровки:**

    l₀,an = (R_s · A_s) / (R_bond · u_s)

**Сопротивление сцепления:**

    R_bond = η₁ · η₂ · R_bt

    η₁ = 2,5 (класс А);  η₂ = 1,0 (d ≤ 32 мм)

**Длина нахлёстки:**

    l_l = α · l₀,an · (A_s,cal / A_s,ef)

    α = 1,2 (растяжение);  α = 0,9 (сжатие)

**Пример (∅16 A500C, B25):**

    R_bond = 2,5 × 1,0 × 1,05 = 2,625 МПа
    l₀,an = (435 × 201) / (2,625 × 50,3) ≈ 662 мм
    l_l = 1,2 × 662 ≈ 795 мм → принято 800 мм

**Минимум:** не менее 20·d_s = 320 мм; не менее 250 мм.

## 10. Анкеровка стержней в зоне торца фундаментной плиты

### Схема анкеровки на торце (рисунок)

```
    Торец плиты:
    
    ┌──────────────────────────────────────┐
    │                                      │
    │     ←── Нижнее армирование ──       │
    │  ════════════════════════╗           │
    │                          ║ ← Отгиб  │
    │                          ║   вверх   │
    │                          ║   l_an    │
    │     ←── Верхнее армирование ──      │
    │  ════════════════════════╗           │
    │                          ║ ← Отгиб  │
    │                          ║   вниз    │
    │                          ║   l_an    │
    └──────────────────────────────────────┘
    ├── Защитный слой ≥ 40 мм ──┤
```

### Формула длины анкеровки

    l_an = α · l₀,an · (A_s,cal / A_s,ef)

    α = 1,0 (растяжение);  α = 0,75 (сжатие)

    q_sw = R_sw · A_sw / S_w  [кН/м]

## 12. Для чего устанавливают фоновое армирование?

### Назначение
1. Восприятие минимальных изгибающих моментов
2. Ограничение ширины раскрытия трещин (усадка, температура)
3. Обеспечение пластичности (нехрупкое разрушение)
4. Каркас для фиксации дополнительных стержней
5. Выполнение μ_s,min ≥ 0,1% (СП 63)

---

## 13. По какому принципу определяется площадь фонового армирования?

### Формула

    μ_s = A_s / (b · h₀) ≥ μ_s,min = 0,1%
    
    A_s,min = 0,001 × 1000 × h₀  [мм²/м.п.]

### Пример (h₀ = 940 мм)

    A_s,min = 0,001 × 1000 × 940 = 940 мм² = 9,4 см²

5 стержней / м (шаг 200): каждый ≥ 188 мм² → **∅16 A500C** (A = 201 мм²)

    A_s,ef = 5 × 201 = 1005 мм² > 940 мм² ✓

## 14. Что такое нахлёст арматуры и как он определяется?

(Ответ объединён с вопросом 9 — формулы и рисунок см. выше.)

### Формулы

    l_l = α · l₀,an · (A_s,cal / A_s,ef)
    l₀,an = (R_s · A_s) / (R_bond · u_s)
    R_bond = η₁ · η₂ · R_bt

### Минимальные значения
- Не менее 0,4·α·l₀,an
- Не менее 20·d_s
- Не менее 250 мм

## 15. Что такое расчётный контур и пирамида продавливания?

### Схема (рисунок)

```
    Вид A-A (план на уровне 0,5·h₀):
    
    ┌────────────────────────────────┐
    │                                │
    │   ┌─────── u_x ──────────┐    │
    │   │                      │    │
    │   │ u_y ┌────────┐       │    │
    │   │     │Колонна │ a × b │    │
    │   │     │        │       │    │
    │   │     └────────┘       │    │
    │   │                      │    │
    │   └──────────────────────┘    │
    │                                │
    │   u_x = a + 2·(0,5·h₀)       │
    │   u_y = b + 2·(0,5·h₀)       │
    └────────────────────────────────┘
    
    u = 2(u_x + u_y) = 2(a + b + 2h₀)
```

### Формулы

    u = 2(a + b + 2h₀)

    F/u + M_x/W_b,x + M_y/W_b,y ≤ γ_b1 · R_bt · h₀

Для крайних/угловых колонн — контур может быть **незамкнутым**.
