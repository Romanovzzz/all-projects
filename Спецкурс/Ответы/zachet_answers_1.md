### 1.3. Конструктивное решение безригельных каркасов

### Схема безригельного каркаса (рисунок)

```
    БЕЗ КАПИТЕЛЕЙ:              С КАПИТЕЛЯМИ:
    
    ═══════════════════        ═══════════════════
    │               │          │    ╱──────╲   │
    │               │          │   ╱  кап.  ╲  │
    │               │          │  ╱          ╲ │
    ║               ║          ║               ║
    ║   Колонна     ║          ║   Колонна     ║
    
    (+) Простая               (+) Большой контур u
        опалубка                  → меньше продавлив.
    (−) Риск                  (−) Сложная опалубка
        продавливания
```

### Формула периметра продавливания
Без капители: u = 2(a + b + 2h₀)
С капителью:  u = 2(a_кап + b_кап + 2h₀)  — значительно больше!

### 1.5. Основные положения расчёта МКЭ

### Схема МКЭ (рисунок)

```
    Расчётная область → Разбивка на КЭ:
    
    ┌──┬──┬──┬──┐
    │  │  │  │  │  ← Пластинчатые КЭ (плиты)
    ├──┼──┼──┼──┤
    │  │  │  │  │
    ├──┼──┼──┼──┤
    │  │  │  │  │
    └──┴──┴──┴──┘
    ║  ║  ║  ║  ║  ← Стержневые КЭ (колонны)
    
    Система уравнений: [K]{u} = {F}
    
    [K] — матрица жёсткости
    {u} — вектор перемещений (неизвестные)
    {F} — вектор нагрузок (известные)
```

### 1.9. «Физическая нелинейность» ЖБ. Методы учёта

### Диаграмма σ–ε бетона (рисунок)

```
    σ_b
    ↑
    │       ╱─╲
    │      ╱   ╲
    │     ╱     ╲  ← Нисходящая ветвь
    │    ╱       ╲    (трещины, разрушение)
    │   ╱         ╲
    │  ╱           ╲
    │ ╱             ╲
    ├╱───────────────╲──→ ε_b
    0  ε_b1     ε_b2
    
    Нелинейность → понижающие коэфф.:
    0,6 E_b (колонны), 0,3 E_b (плиты)
```

**Методы:**
1. Линейный с пониженными жёсткостями (массовый)
2. Метод монтажных стадий (поэтажно)
3. Физически нелинейный (итерационный, точный)
4. Деформационная модель (СП 63)

### 2.2. Складчатые и висячие покрытия

### Схема висячего покрытия (рисунок)

```
    ┌── Опорный контур (жёсткое кольцо) ──┐
    │          ╱────────────╲               │
    │         ╱              ╲              │
    │   f ↕  ╱   Тросы        ╲            │
    │       ╱   (ванты)        ╲           │
    │      ╱                    ╲          │
    │     ╱──────────────────────╲         │
    └──────────────────────────────────────┘
    
    Пролёты до 200+ м!
    f — стрела провисания
    ↑f → ↓усилия в тросах, но ↑высота
```

---

### 2.3. Принципы расчёта висячих покрытий

### Формула усилия в тросе

    T = q·L² / (8·f)

где: q — распределённая нагрузка; L — пролёт; f — стрела провисания.

**Также:** расчёт опорного контура на сжатие; учёт аэродинамической неустойчивости; геометрически нелинейный расчёт.

---

### 2.4. Конструирование пространственных составных элементов

- Узлы: сварка закладных, выпуски арматуры, замоноличивание
- Рёбра жёсткости: утолщения на краях панелей
- Предварительное напряжение: при больших пролётах
- Диафрагмы: предотвращение выпучивания

### 3.4. Определение ветровой нагрузки на дымовые трубы

### Формула

    w = w₀ · k(z) · c  [кПа]

| Параметр | Значение |
|---|---|
| w₀ | Нормативное давление для ветрового района |
| k(z) | Коэффициент по высоте (тип местности A/B/C) |
| c | Аэродинамический коэфф. (~0,6 для цилиндра) |

Динамическая составляющая усиливает статику за счёт пульсаций.

---

### 3.5. Фундаменты дымовых труб

### Формулы краевых давлений

    p_max = N/A + M/W
    p_min = N/A − M/W

**Условие:** p_min ≥ 0 (отсутствие отрыва).

```
    Эпюра давлений:
    
    ┌────────────────────────┐
    │ p_max                 p_min│
    │ ████████████████      ████│
    │ ████████████████████  ████│
    └────────────────────────┘
    
    p_min ≥ 0 → нет отрыва ✓
```
