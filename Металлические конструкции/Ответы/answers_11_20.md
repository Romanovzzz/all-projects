## Вопрос 11. Сбор нагрузок на ферму (постоянная, снеговая)

### 1. Постоянная нагрузка на ферму

Расчётная равномерно распределённая нагрузка от веса покрытия:

    qп = gп · B

где gп — расчётная нагрузка от покрытия (кПа): профлист, прогоны, утеплитель, стяжка, гидроизоляция (≈ 1,05 кПа — по табл. 3.1 Туснина-Бергера); B — шаг рам (м).

Расчётная сосредоточенная нагрузка в рядовой узел:

    Fп = qп · lф

Расчётная сосредоточенная нагрузка в крайний узел:

    F'п = qп · lф,кр

где lф = 3 м — шаг узлов фермы; lф,кр = 1,5 м — расстояние от опоры до первого узла.

Пример (по Туснину-Бергеру):
- qп = 1,05 · 12 = 12,6 кН/м → Fп = 12,6 · 3 = 37,8 кН; F'п = 12,6 · 1,5 = 18,9 кН.

### 2. Снеговая нагрузка на ферму

    qсн = S · B = S₀ · γf · B

Три варианта распределения μ (по прил. Б.1 СП 20):
- Вариант 1: μ = 1 (равномерное);
- Вариант 2: μ = 0,9 (с одной стороны) и μ = 1,1 (с другой);
- Вариант 3: другая комбинация.

Сосредоточенная снеговая нагрузка:

    Fсн = qсн · lф;    F'сн = qсн · lф,кр

Пример (г. Липецк, Sg = 1,50 кПа):
| μ | S₀, кПа | S, кПа | qсн, кН/м | Fсн, кН |
|---|---|---|---|---|
| 1 | 1,50 | 2,10 | 25,2 | 75,6 |
| 0,9 | 1,35 | 1,89 | 22,7 | 68,0 |
| 1,1 | 1,65 | 2,31 | 27,7 | 83,1 |

## Вопрос 12. Расчёт ферм. Определение усилий в стержнях ферм

### Методы определения усилий

**1. Метод вырезания узлов:**
- Ферма разбивается на свободные узлы; для каждого узла составляются уравнения равновесия ΣX = 0, ΣY = 0.
- Применяется последовательно, начиная с опорного узла.

**2. Метод сечений (метод Риттера):**
- Ферма рассекается на две части, для одной из частей составляются 3 уравнения равновесия.
- Рационально для определения усилий в отдельных стержнях.

**3. Конечно-элементный расчёт (по Туснину-Бергеру):**
- Ферма моделируется как часть пространственного каркаса в ПК (ЛИРА-САПР, SCAD).
- Стержни решётки — шарнирные (шарниры UY, UZ в обоих узлах).
- Пояса — жёсткие стержни.
- Усилия определяются для каждого загружения, затем формируются расчётные сочетания усилий (РСУ).

### Результаты расчёта
По рис. 4.8 Туснина-Бергера: усилия в стержнях фермы получают из конечно-элементного расчёта. Для каждого элемента определяется максимальное сжимающее/растягивающее усилие N.

### Узловая нагрузка на ферму
Нагрузки прикладываются к узлам верхнего пояса:
- Рядовые узлы: F = q · lф
- Крайние узлы: F' = q · lф,кр

Верхний пояс — сжат, нижний — растянут (при загружении сверху). Опорные раскосы — наиболее нагружены (сжаты).

## Вопрос 13. Типы сечений элементов. Расчётные длины стержней ферм

### Типы сечений элементов ферм (по Туснину-Бергеру, табл. 4.1)

**1. Парные уголки (основной тип):**

| Элемент | Сечение |
|---|---|
| Нижний пояс | 2L180×12 (g = 10 мм) |
| Верхний пояс | 2L200×12 (g = 10 мм) |
| Опорные раскосы | 2L160×10 (g = 10 мм) |
| Рядовые раскосы | 2L125×8 (g = 10 мм) |
| Стойки | 2L75×6 (g = 10 мм) |

g — зазор между уголками (определяется толщиной фасонки, обычно 10–14 мм).

**2. Другие типы сечений:**
- Тавровые (из прокатных | разрезных двутавров) — для тяжёлых ферм.
- Трубчатые (круглые и прямоугольные) — для лёгких ферм.
- Одиночные уголки — для лёгких стоек и подвесок.

### Расчётные длины стержней ферм

**В плоскости фермы:**

    lef,x = l  (полная геометрическая длина стержня между узлами)

**Из плоскости фермы:**
- **Для поясов:** lef,y = l₁ — расстояние между точками закрепления из плоскости (прогонами, распорками, связями).
- **Для решётки:** lef,y = l — геометрическая длина.

Если к узлу верхнего пояса в каждом узле крепится прогон — lef,y для верхнего пояса = шагу прогонов. Для нижнего пояса — lef,y = расстоянию между растяжками ГС или распорками.

### Предельные гибкости (п. 10.4.1 СП 16)
- Сжатые стержни: [λ] = 120 (основные), [λ] = 150 (второстепенные);
- Растянутые: [λ] = 250 (при статической нагрузке); [λ] = 150 (при динамической).

## Вопрос 14. Расчётные длины колонн промышленных зданий

### В плоскости поперечной рамы (по п. 10.3.1 СП 16 и Туснину-Бергеру, п. 5.1.1)

    lef = μ · l

где μ — коэффициент расчётной длины (прил. И, СП 16); l — геометрическая длина участка колонны.

**Для нижней части колонны:**

    l(z)_Н = μ₁ · Hн

μ₁ определяется по табл. И.2 СП 16 в зависимости от:

    α = (l₂/l₁) · √(I₁/I₂);    β = N₁/N₂;    n = (I₂·l₁)/(I₁·l₂)

Пример (Туснина-Бергер): I₁/I₂ = 5 (предварительно), N₁ = 4500 кН, N₂ = 821 кН → α = 0,418, β = 5,48, n = 0,457 → μ₁ = 1,761.

**Для верхней части колонны:**

    μ₂ = μ₁/√α ≤ 3

Пример: μ₂ = 1,761/√0,418 = 4,213 > 3 → принимается μ₂ = 3,0.

    l(y)_В = μ₂ · Hв = 3 · 7,37 = 22,11 м

### Из плоскости поперечной рамы

Каркас работает по связевой схеме. Расчётная длина = наибольшему расстоянию между точками закрепления от смещений вдоль здания:

- **Нижняя часть:** l(y)_Н = Hн (от базы до уровня нижнего пояса подкрановой балки).
- **Верхняя часть:** l(z)_В = Hв – hб (от уровня верхнего пояса подкрановой балки до распорки по нижнему поясу фермы).

Пример: l(z)_В = 7,37 – 1,8 = 5,57 м.

## Вопрос 15. Типы сечений колонн промышленных зданий

### Классификация по типу сечения

**1. Сплошные колонны:**
- Прокатный двутавр (для лёгких кранов, Q ≤ 20 т).
- Сварной двутавр (основной тип для верхней части ступенчатой колонны; по Туснину-Бергеру: стенка tw = 8 мм, полки bf×tf = 400×18 мм, общая высота hв = 700 мм).

**2. Сквозные (решётчатые) колонны:**
Применяются при hн > 1000 мм (по Туснину-Бергеру).
- Двухветвевая с раскосной решеткой — основной тип для нижней части ступенчатой колонны.
- **Подкрановая ветвь**: прокатный двутавр I70Б2 / I70Б3 (ГОСТ Р 57837-2017).
- **Наружная ветвь**: сварной швеллер (по Туснину-Бергеру: стенка hw2 = 750 мм, tw2 = 18 мм, полки bf2 = 300 мм, tf2 = 22 мм).
- Решетка — раскосная, из прокатных уголков L125×9.

### Ступенчатые колонны
Наиболее распространённый тип для промзданий с кранами:
- **Верхняя часть** (надкрановая) — сплошное сварное двутавровое сечение.
- **Нижняя часть** (подкрановая) — сквозное двухветвевое сечение.
- Соединение через **траверсу** (балку-траверсу) — сварное двутавровое сечение.

### Условия жёсткости

    hв ≥ Hв/12  (верхняя часть)
    hн ≥ H/15  (при 7К–8К)  или  hн ≥ H/20  (при 1К–6К)

### Условия местной устойчивости

**Стенка верхней части (п. 9.4.2 СП 16):**

    λ̄w = (hw/tw) · √(Ry/E) ≤ λ̄uw

При λ̄w > λ̄uw — допускается местная потеря устойчивости стенки (п. 9.4.6); берётся уменьшенная расчётная площадь Ad (п. 7.3.6).

**Полка (п. 9.4.7 СП 16):**

    λ̄f = (bef/tf) · √(Ry/E) ≤ λ̄uf

Пример (Туснина-Бергер): bf = 400 мм, tf = 18 мм → λ̄f = 0,372 ≤ 0,418 — OK.

## Вопрос 16. Расчёт колонн промышленных зданий сплошного сечения

### Расчёт верхней части колонны (по п. 9.2.2 СП 16 и Туснину-Бергеру, п. 5.1.2)

**Проверка устойчивости в плоскости действия момента:**

    N/(φe · A · Ry · γc) ≤ 1

где φe — коэффициент устойчивости при сжатии с изгибом (табл. Д.3 СП 16); A = Ad (уменьшенная площадь при потере местной устойчивости стенки); γc = 1,05 (для колонн промзданий с мостовыми кранами).

**Определение φe:**
Зависит от условной гибкости λ̄y и приведённого относительного эксцентриситета mef:

    λ̄y = (lef/iy) · √(Ry/E)

    mef = η · m

где η — коэффициент влияния формы сечения (табл. Д.2 СП 16, тип 5):

    η = (1,75 – 0,1m) – 0,02(5 – m) · λ̄y  (при Af/Aw = 0,5)

    m = e·A/W  (относительный эксцентриситет)

    e = M/N  (эксцентриситет)

Для симметричного двутавра: W ≈ A·hв/0,35; iy ≈ 0,42·hв.

**Требуемая площадь сечения:**

    Aтр = N/(φe · Ry · γc)

### Проверка устойчивости из плоскости действия момента (п. 9.2.4 СП 16)

    N/(c · φz · A · Ry · γc) ≤ 1

где φz — коэффициент устойчивости при центральном сжатии относительно оси z; c — коэффициент (п. 9.2.5 СП 16):
- При m ≤ 5: c = 1/(1 + α·m);
- При 5 < m < 10: c = c₅(2 – 0,2m) + c₁₀(0,2m – 1);
- При m ≥ 10: c₁₀ = 1/(1 + m/(φb·φz)).

Пример (Туснина-Бергер): N = 571,22 кН, M = 844,2 кНм, mef = 7,237 → φe = 0,153 → Aтр = 148,15 см².

## Вопрос 17. Расчёт колонн промышленных зданий сквозного сечения

### Подбор сечений ветвей (по Туснину-Бергеру, п. 5.1.3)

Расчёт ветвей — на устойчивость при **центральном сжатии** в плоскости рамы (относительно местной оси z):

    N/(φz · A · Ry · γc) ≤ 1

**Подкрановая ветвь** (прокатный двутавр):

    Aтр,1 = N₁/(φz · Ry · γc)

где N₁ = Nв1,max (максимальное усилие в подкрановой ветви, по РСУ); φz — предварительно ≈ 0,8.

Условная гибкость ветви:

    λ̄z1 = (lz1/iz1) · √(Ry/E) ≤ 2,7

где lz1 — шаг узлов решетки (≈ hн ÷ высоте сечения нижней части).

**Наружная ветвь** (сварной швеллер):
Аналогичный расчёт. Высота стенки швеллера = h₁ + 2·20 мм (для сварных швов), где h₁ — высота подкрановой ветви. Условие местной устойчивости полки: bf/tf ≤ 15.

### Проверка устойчивости нижней части колонны как сквозного стержня (п. 9.2.2 СП 16)

    N/(φe · A · Ry · γc) ≤ 1

Момент инерции сквозного стержня: Iz — относительно свободной оси z.

Приведённая гибкость (табл. 8 СП 16, тип 1 — с решетками):

    λef = √(λ² + α · A/Ad1)

где Ad1 — площадь раскосов; α = d³/(b²·lb) — коэффициент; d — длина раскоса; b = h₀ — расстояние между осями ветвей; lb — шаг решетки.

Относительный эксцентриситет:

    m = e·A·a/Iz

где a = y₁ или y₂ — расстояние от оси сквозного стержня до оси ветви.

Пример (Туснина-Бергер): λef = 39,25, λ̄ef = 1,34 → N = 4533 кН, проверка 0,838 ≤ 1 — устойчивость обеспечена.

## Вопрос 18. Расчёт решётки сквозной колонны

### Назначение решётки
Соединительная решетка связывает ветви сквозного стержня и воспринимает:
1. **Фактическую поперечную силу** Q (от статического расчёта каркаса).
2. **Фиктивную поперечную силу** Qfic — условная сила, моделирующая стремление ветви к потере устойчивости.

### Фиктивная поперечная сила (п. 7.2.7 СП 16)

    Qfic = 7,15·10⁻⁶ · (E/Ry – 2330/φ) · N

где N — максимальное сжимающее усилие в сквозном стержне; φ — минимальный коэффициент устойчивости ветви (min из φz1, φz2).

На одну грань решетки:

    Qs = Qfic/2

### Продольное усилие в раскосе (п. 7.2.9 СП 16)

    Nd,fic = α₁ · Qs · d/b

где α₁ = 1 (для раскосной решетки); d — длина раскоса; b = h₀ — расстояние между осями ветвей.

Расчётное усилие в раскосе — **наибольшее** из:
- Nd (фактическое, из РСУ конечно-элементного расчёта)
- Nd,fic (фиктивное)

### Проверка устойчивости раскоса (п. 7.1.3 СП 16)

    Nd/(φz · Ad · Ry · γc) ≤ 1

Требуемая площадь:

    Ad,тр = Nd/(φz · Ry · γc)

Гибкость раскоса: λ = d/imin.

Пример (Туснина-Бергер): Qfic = 66,67 кН → Qs = 33,34 кН → Nd,fic = 49,62 кН < Nd = 218,26 кН → принимаем Nd = 218,26 кН. Уголок L125×9 → N/(φ·A·Ry·γc) = 0,774 ≤ 1 — OK.

### Конструктивные требования
- Решетка раскосная из прокатных уголков.
- Двухплоскостная (в обеих плоскостях граней ветвей).
- Крепление раскосов к полкам ветвей — сварными швами.
- Шаг узлов решетки ≈ hн (высота нижней части колонны) = 1750 мм = 350 мм × 5.

## Вопрос 19. Конструкция и расчёт сопряжения верхней и нижней части колонны

### Конструкция узла (по Туснину-Бергеру, п. 8.1)

Узел сопряжения включает:
1. **Балку-траверсу** — горизонтальный элемент, сварной двутавр, через который передаются усилия от верхней части колонны к ветвям нижней части.
2. **Вертикальные рёбра** — обеспечивают передачу сосредоточенных сил.
3. **Сварные швы** крепления траверсы к ветвям колонны.

### Работа узла
- Траверса воспринимает изгибающий момент M и продольную силу N от верхней части колонны.
- Момент передаётся парой сил на ветви: Nтр = M/h₀.
- Продольная сила распределяется между ветвями пропорционально расстояниям до центра тяжести.
- Давление от кранов Dmax передаётся непосредственно на подкрановую ветвь через плиту кранового рельса и подкрановую балку.

### Моделирование в расчётной схеме (по Туснину-Бергеру, п. 4.1)
- Траверса моделируется горизонтальным элементом (тип жесткости 5), жёсткость соответствует балке-траверсе.
- Верхний раскос колонны всегда примыкает к подкрановой ветви ниже оси траверсы на ≈ 500 мм.
- В расчётной модели — крепление раскосов к ветвям через жёсткие вставки (тип 13), шарнирные (UY, UZ).

### Проверки
1. **Прочность траверсы на изгиб:** M/(Wтр · Ry · γc) ≤ 1.
2. **Прочность сварных швов** крепления траверсы к подкрановой ветви.
3. **Прочность стенки траверсы** на местное давление от подкрановой балки.
4. **Устойчивость стенки** траверсы.

## Вопрос 20. Базы внецентренно сжатых колонн

### Конструкция базы (по Туснину-Бергеру, п. 8.3)

База внецентренно сжатой колонны включает:
1. **Опорную плиту** — передаёт нагрузку на фундамент, распределяя давление по поверхности бетона.
2. **Траверсы** (вертикальные рёбра) — передают усилия с ветвей колонны на опорную плиту.
3. **Анкерные болты** — воспринимают отрывающие усилия при неблагоприятных сочетаниях нагрузок (ветер + минимальная постоянная).
4. **Рёбра жёсткости** — усиливают опорную плиту, предотвращая её чрезмерный изгиб.

### Расчёт опорной плиты

**Определение размеров плиты из условия прочности фундамента:**

    σф = N/Aпл ≤ Rф

Для внецентренно сжатой колонны (двухветвевой):
- Каждая ветвь имеет свою базу.
- Размеры плиты каждой ветви: b × l (определяются из прочности бетона фундамента).

**Расчёт толщины плиты:**
Плита работает на изгиб от реактивного давления фундамента:

    Mпл = σmax · b² / 2  (консольный участок)

    tпл = √(6·Mпл/(Ry·γc))

### Расчёт анкерных болтов (по Туснину-Бергеру, п. 4.3)

Для определения отрывающего усилия составляются специальные сочетания:
- Постоянные нагрузки с γf = 0,9 (п. 7.3 СП 20): k = 0,9/γf.
- Пример: для L1: k = 0,9/1,05 = 0,857; для L2: k = 0,9/1,13 = 0,796.
- Добавляется ветровая нагрузка с максимальным опрокидывающим моментом.

Усилие в анкерных болтах:

    Nа = M/h₀ – N/2  (при M > N·h₀/2 — возникает отрыв)

### Расчёт траверс базы
Траверсы работают как консольные балки, нагруженные реактивным давлением плиты:

    Mтр = σ · b · c² / 2  (c — вылет консоли)

Проверка прочности по нормальным напряжениям:

    σ = Mтр/Wтр ≤ Ry · γc

Проверка прочности сварных швов крепления траверсы к ветви колонны:

    τш = N/(β·kш·lш) ≤ Rwf·γc  (для угловых швов)
